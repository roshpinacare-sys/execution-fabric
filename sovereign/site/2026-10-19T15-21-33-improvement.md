# צ'ק-ליסט אתחול יומי למשמרת-לילה: בדיקות בסיס לפני כניסה לעורקי-הלב

## צ'ק-ליסט אתחול יומי למשמרת-לילה

הקונסולה מריצה את הבדיקות הבאות אוטומטית עם כניסה למשמרת-לילה (עורקי-הלב). כל בדיקה מחזירה `PASS`/`FAIL` עם קוד ופירוט בתצוגה.

### בדיקות חובה
- [ ] חיבור לשרשרת-אמת: אימות hash של הבלוק האחרון מול ה-genesis
- [ ] זמינות שער-העברה לגיט: פינג ל-/api/handoffs עם timeout 2s
- [ ] תור משימות חירום ריק: אין משימות במצב `PENDING` למעלה מ-5 דקות
- [ ] זיכרון פנוי: יותר מ-200MB זמין לפי /api/arsenal/memory
- [ ] צי-הכלים מגיב: קריאה ל-/api/arsenal/status מחזירה `ready`
- [ ] מפת-הריבונות מעודכנת: timestamp אחרון מ-/api/census פחות מ-6 שעות

### תצוגה בקונסולה
- כל בדיקה מוצגת כשורה עם אייקון ✅/❌
- כישלון מפעיל התראה צהובה בשורת-הסטטוס ומכניס את המשמרת למצב `degraded`
- הצלחה בכל הבדיקות מפעילה מצב `green` ופותחת את לוח-המשימות לעריכת משימות חירום

הצ'ק-ליסט מאוחסן ב-localStorage תחת key `nightshift.init.v1` כדי לשחזר אחרי רענון.
