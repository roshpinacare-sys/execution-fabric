# מדריך למשתמשים חדשים: טעויות נפוצות בשבוע הראשון

ברוכים הבאים לרשת הביצוע! כמשתמשים חדשים, עלולים להתמודד עם מספר אתגרים נפוצים. המדריך הזה יעזור לכם להתחיל את הדרך בצורה חלקה יותר.

## טעות נפוצה #1: התעלמות מהתראות הרשת
**בעיה:** משתמשים חדשים לעתים מתעלמים מהתראות הרשת המופיעות בקונסולה, מה שמוביל לביצועים לא אופטימליים.
**פתרון:**
1. שימו לב לסמל הפעמון בפינה הימנית העליונה של הקונסולה
2. לחצו עליו כדי לצפות בהתראות פעילות
3. התראות בצבע אדום מציינות פעולות דחופות שדורשות תשומת לב
4. התראות בצבע צהוב מציינות המלצות לשיפור ביצועים

**דוגמה מעשית:**
```
[פעמון] 🔴 3 משימות במצב "FAILED" דורשות טיפול
לחצו כאן לפתרון מהיר
```

## טעות נפוצה #2: שימוש לא נכון בלוח המשימות
**בעיה:** משתמשים חדשים מתבלבלים בין מצבי המשימות ומקצים משימות לא לעובדים המתאימים.
**פתרון:**
1. קראו את התיאור המלא של כל משימה לפני הקצאה
2. השתמשו בפילטרים בצד שמאל כדי לסנן לפי מומחיות העובדים
3. הקצו תמיד משימות עם סימן "HIGH" ראשונה
4. עקבו אחרי התקדמות המשימות באמצעות גרף ה-Gantt

**דוגמה מעשית:**
```
[לוח המשימות] → פילטרים → מומחיות: "אבטחה" → מצב: "פתוח"
```

## טעות נפוצה #3: התעלמות משרשרת האמת
**בעיה:** משתמשים חדשים לא מבינים את חשיבות שרשרת האמת (Ledger hash-chain) ומתעלמים מהיסטוריית השינויים.
**פתרון:**
1. בקרו בקטע "שרשרת האמת" בתפריט הראשי
2. למדו איך לעקוב אחרי שרשרת השינויים
3. השתמשו בפונקציית החיפוש כדי למצוא שינויים ספציפיים
4. בדקו את גודל הבלוקים ואת תדירות העדכונים

**דוגמה מעשית:**
```
[שרשרת האמת] → הצג לפי: תאריך → חפש: "UI-2023"
```

## טעות נפוצה #4: ניצול לא מיטבי של כלי הארסנל
**בעיה:** משתמשים חדשים לא משתמשים בכלי הארסנל ביעילות, מה שמאט את קצב העבודה.
**פתרון:**
1. צפו בסרטוני ההדרכה הקצרים עבור כל כלי בארסנל
2. הגדירו קיצורי מקלדת אישיים לכלים המשמשים אתכם לעתים קרובות
3. השתמשו בפונקציית ההמלצות של המערכת כדי לגלות כלים חדשים
4. דווחו על כלים שאינם פועלים כראוי באמצעות תפריט התמיכה

**דוגמה מעשית:**
```
[צי הכלים] → סרטוני הדרכה → בחרו כלי → הגדירו קיצור מקלדת
```

## טעות נפוצה #5: אי הבנה של מערכת המדדים
**בעיה:** משתמשים חדשים לא מבינים איך לקרוא את מדדי הרשת ומתעלמים מנתונים חשובים.
**פתרון:**
1. צפו במדריך המפורט למדדים בקטע "מדדי רשת"
2. הגדירו תצורה אישית של לוח המדדים כדי להציג רק את הנתונים הרלוונטיים לכם
3. הגדירו התראות לשינויים חריגים במדדים מפתח
4. השתמשו בפונקציית ההשוואה כדי להשוות בין תקופות זמן שונות

**דוגמה מעשית:**
```
[מדדי רשת] → הגדרות → לוח מדדים אישי → הגדר התראות → השווה תקופות
```

## סיכום
הימנעות מטעויות אלה תחסוך לכם זמן רב ותאפשר לכם לנצל את מלוא הפוטנציאל של רשת הביצוע. זכרו שכל משתמש חדש עובר תהליך למידה - השאירו לעצמך סבלנות והשתמשו במשאבי העזרה הזמינים.

לשאלות נוספות, פנו למרכז התמיכה או למדריך המלא בקטע "שאלות ותשובות נפוצות".
