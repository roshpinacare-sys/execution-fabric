# מדריך תפעול: ניהול תורים והקצאות בלוח-המשימות

> **קהל יעד**: מפעילי קונסולה, מנהלי משמרת, מפתחים המשתמשים ב-Dispatch → Workers
> **משך קריאה משוער**: 8 דקות

---

## 1. סקירה מהירה של הלוח

לוח-המשימות מורכב משלושה אזורים עיקריים:

| אזור | תפקיד | אינדיקטור בריאות |
|-------|--------|-------------------|
| **תור נכנס (Inbox)** | משימות חדשות הממתינות להקצאה | ספירה > 50 = עומס |
| **בעבודה (Active)** | משימות המוקצות לעובדים פעילים | יחס Active/Workers ≈ 1:1 אידיאלי |
| **הושלמו (Done)** | משימות שהסתיימו בהצלחה | קצב השלמה/שעה |

**פקודת קונסולה מהירה**:
```bash
# תצוגת מצב כללי
saos dispatch status --compact
```

## 2. זרימת עבודה יומית מומלצת

### 2.1 פתיחת משמרת (08:00–09:00)
1. **בדיקת בריאות עובדים**
   ```bash
   saos workers list --status=online --verbose
   ```
   - ודא שלפחות 80% מהעובדים הצפויים מחוברים
   - סמן עובדים במצב `degraded` לבדיקה

2. **ניקוי תור נכנס**
   ```bash
   # הצג משימות הממתינות > 30 דקות
   saos dispatch queue inbox --stale=30m
   ```
   - הקצה משימות דחופות לעובדים פנויים
   - דחה/בטל משימות לא רלוונטיות (`saos dispatch reject <id> --reason`)

3. **הגדרת יעדי יום**
   - קבע יעד השלמות (למשל: 120 משימות/יום)
   - עדכן בלוח: `saos dispatch target set --daily=120`

### 2.2 ניטור שוטף (כל 30–60 דקות)
```bash
# סנכרון מהיר
saos dispatch pulse
```

**מה לחפש**:
- ⚠️ תור נכנס גדל בקצב > 10 משימות/דקה
- ⚠️ עובדים במצב `idle` בעוד תור פעיל
- ⚠️ משימות ב-Active מעל 45 דקות ללא התקדמות

### 2.3 טיפול בחריגים

| תרחיש | פקודה | הערות |
|---------|--------|--------|
| עובד נתקע | `saos worker restart <id> --graceful` | שומר הקשר משימה |
| משימה תקועה | `saos dispatch reassign <task-id> --to=<worker-id>` | עדיף עובד עם עומס נמוך |
| עומס פתאומי | `saos workers scale +2 --pool=general` | דורש קיבולת פנויה |
| שגיאה חוזרת | `saos dispatch quarantine <task-id> --analyze` | מעביר לבדיקה נפרדת |

### 2.4 סגירת משמרת (17:00–18:00)
1. **השלמה/העברה של משימות פעילות**
   ```bash
   # משימות שניתן לסיים ב-15 דק'
   saos dispatch active --eta=15m --finish
   ```

2. **העברת שארית למשמרת הבאה**
   ```bash
   saos dispatch handoff prepare --shift=night --summary
   ```
   מייצר דוח העברה אוטומטי עם:
   - משימות פתוחות וסטטוס
   - עובדים בעייתיים
   - החלטות שהתקבלו

3. **ארכוב יומי**
   ```bash
   saos dispatch archive --date=today --compress
   ```

## 3. תרחישים נפוצים ופתרונות

### תרחיש א: "התור לא זז — עובדים מחוברים אבל לא מושכים"
**אבחון מהיר**:
```bash
saos workers inspect --all --fields=currentTask,lastHeartbeat,errorCount
```
**סיבות אופייניות**:
- הגדרת `concurrency` נמוכה מדי בקונפיגורציית העובד
- משימות דורשות resource שאינו זמין (DB connection, API quota)
- באג בקוד המשימה הגורם ל-crash שקט

**פתרון**:
1. הגדל concurrency זמנית: `saos worker config <id> --concurrency=+2`
2. בדוק לוגי שגיאה: `saos worker logs <id> --errors --since=1h`
3. אם בעיה מערכתית — הפעל `saos dispatch pause --reason="investigation"`

### תרחיש ב: "משימות נכשלות בשיעור גבוה פתאומי"
**סף התראה**: > 15% כשלון ב-10 דקות

**רצף פעולות**:
```bash
# 1. זהה דפוס שגיאה
saos dispatch failed --since=10m --group=errorType

# 2. אם שגיאה זהה — עצור הקצאת משימות מאותו סוג
saos dispatch pause --task-type=<type> --reason="error spike"

# 3. תיקון/החזרה לאחור
# 4. חידוש הדרגתי
saos dispatch resume --task-type=<type> --ramp=10%
```

### תרחיש ג: "עובד חדש לא מקבל משימות"
**בדיקות**:
```bash
saos worker verify <new-worker-id> --full
```
**רשימת תיוג**:
- [ ] מפתח API תקין ומוגדר
- [ ] תוויות (labels) תואמות לסוגי משימות
- [ ] רשת/פיירוול מאפשר חיבור ל-Dispatch
- [ ] גרסת קוד תואמת (הרץ `saos worker version <id>`)

## 5. מדדי הצלחה יומיים (KPIs)

| מדד | יעד | מקור נתונים |
|-----|------|-------------|
| קצב השלמה | ≥ 120/יום | `saos metrics throughput --daily` |
| זמן המתנה ממוצע בתור | < 5 דקות | `saos metrics queue-wait --avg` |
| שיעור כשלון | < 3% | `saos metrics failure-rate --daily` |
| ניצולת עובדים | 70–85% | `saos metrics worker-util --avg` |
| זמן תגובה לחריג | < 10 דקות | ידני / יומן משמרת |

## 6. טיפים מתקדמים

### תיוג משימות לניתוב חכם
```bash
# הוסף תוויות בעת יצירה
saos dispatch create --payload='{}' --labels="priority:high,team:backend,retryable:true"
```
עובדים עם `labelSelector` מתאים ימשכו אותן ראשונים.

### פרופילי עומס מוגדרים מראש
```bash
# פרופיל "עומס גבוה" — יותר עובדים, concurrency מוגבר
saos dispatch profile apply high-load

# פרופיל "תחזוקה" — הקפאת תורים חדשים
saos dispatch profile apply maintenance
```

### אוטומציה עם Webhooks
הגדר webhook על אירועי `queue.backlog_exceeded` ו-`worker.health_degraded` להתראות Slack/Telegram.

```text
────────────────────────────────────────────────────
תור תקוע               →  saos dispatch queue inbox --stale=10m

```
