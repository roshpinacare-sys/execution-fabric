# הדגשת שורת משימה פעילה עם קיצור מקלדת למעבר מהיר

## הצעה: ניווט מקלדת מלא בטבלת המשימות

### הבעיה
בקונסולת הניהול, טבלת המשימות (Dispatch → Workers) מציגה עשרות שורות. כיום אין אינדיקטור ברור לשורה שנבחרה, ואין דרך לעבור בין שורות במקלדת — המשתמש נאלץ להשתמש בעכבר לכל פעולה (צפייה בפרטים, ביטול, תעדוף).

### הפתרון המוצע
1. **מצב בחירה (Focused Row)** — שורה שמקבלת פוקוס מקבלת:
   - רקע מודגש (`--color-row-focus: #1e3a5f` במצב כהה / `#dbeafe` במצב בהיר)
   - מסגרת צד שמאלית עבה 3px בצבע הדגשה (`--color-accent`)
   - צל עדין (`box-shadow: inset 3px 0 0 var(--color-accent)`)

2. **קיצורי מקלדת**:
   | קיצור | פעולה |
   |--------|--------|
   | `Alt + J` / `↓` | שורה הבאה |
   | `Alt + K` / `↑` | שורה קודמת |
   | `Enter` / `Space` | פתיחת פרטי משימה (Modal) |
   | `Esc` | סגירת פרטים / הסרת פוקוס |
   | `Alt + C` | העתקת מזהה משימה ללוח |
   | `Alt + R` | תעדוף מחדש (Re-queue) |

3. **התנהגות**:
   - בטעינת הטבלה, השורה הראשונה מקבלת פוקוס אוטומטית
   - גלילה אוטומטית (scrollIntoView) כשהפוקוס יוצא מהאזור הנראה
   - מצב הפוקוס נשמר בעת רענון נתונים (polling)

### מימוש טכני
```typescript
// הוספה ל-TaskTable.tsx
const [focusedIndex, setFocusedIndex] = useState(0);

useEffect(() => {
  const handler = (e: KeyboardEvent) => {
    if (e.target instanceof HTMLInputElement) return;
    switch (e.key) {
      case 'j': case 'ArrowDown':
        if (e.altKey || !e.ctrlKey) { e.preventDefault(); setFocusedIndex(i => Math.min(i+1, rows.length-1)); }
        break;
      case 'k': case 'ArrowUp':
        if (e.altKey || !e.ctrlKey) { e.preventDefault(); setFocusedIndex(i => Math.max(i-1, 0)); }
        break;
      case 'Enter': case ' ':
        e.preventDefault(); openDetails(rows[focusedIndex]);
        break;
      case 'Escape':
        closeDetails(); setFocusedIndex(-1);
        break;
    }
  };
  window.addEventListener('keydown', handler);
  return () => window.removeEventListener('keydown', handler);
}, [rows.length]);
```

CSS מינימלי:
```css
.task-row.focused {
  background: var(--color-row-focus);
  box-shadow: inset 3px 0 0 var(--color-accent);
  outline: none;
}
.task-row.focused:focus-visible {
  outline: 2px solid var(--color-accent);
  outline-offset: -2px;
}
```

### מדדי הצלחה
- זמן ממוצע לפתיחת פרטי משימה יורד ב-40% (מדידת Telemetry קיימת)
- 0 תלונות על "איבוד מקום" בטבלה אחרי רענון
- נגישות: עובר בדיקת axe-core ל-Keyboard Navigation

### סיכון נמוך
- שינוי CSS/JS מקומי בלבד, ללא שבירת API
- תואם RTL אוטומטית (כיוון המסגרת מתהפך)
- ניתן לכיבוי דרך הגדרת משתמש (`prefersReducedMotion` מכובד)
