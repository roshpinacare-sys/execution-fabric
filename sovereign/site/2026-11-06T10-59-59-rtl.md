# התאמת קונסולת RTL למובייל: פריסת כרטיסים רספונסיבית עם נגישות מלאה

# הצעה: התאמת קונסולת RTL למובייל — פריסת כרטיסים רספונסיבית

## הבעיה
הקונסולה הנוכחית מציגה נתונים בטבלאות HTML רחבות (`<table>`) עם עמודות רבות. במובייל (≤ 480px) הטבלאות נגזרות, דורשות גלילה אופקית, ואינן נגישות לקוראי מסך (חסרות `scope`, `aria-label`, כותרות טבלה).

## הפתרון — פריסת כרטיסים (Card Layout)

### 1. נקודת שבירה (Breakpoint)
```css
@media (max-width: 480px) {
  .data-table thead { display: none; }
  .data-table tbody tr { display: block; margin-bottom: 1rem; border: 1px solid var(--border); border-radius: 8px; padding: 0.75rem; }
  .data-table td { display: flex; justify-content: space-between; padding: 0.4rem 0; border-bottom: 1px solid var(--border-muted); }
  .data-table td::before { content: attr(data-label); font-weight: 600; color: var(--text-muted); }
  .data-table td:last-child { border-bottom: none; }
}
```

### 2. תכונות HTML נדרשות בכל `<td>`
```html
<td data-label="שם המשימה" data-value="task-42">task-42</td>
<td data-label="סטטוס" data-value="DONE"><span class="badge done">DONE</span></td>
```

### 3. נגישות (a11y)
- **כותרות טבלה**: `<caption>` גלוי או `aria-label` על `<table>`.
- **תאי כותרת**: `<th scope="col">` בגרסת דסקטופ.
- **מצב ניגודיות גבוה**: משתני CSS `var(--text)`, `var(--border)` מותאמים אוטומטית דרך `prefers-contrast: more`.
- **ניווט מקלדת**: `tabindex="0"` על שורות כרטיס במובייל, `Enter`/`Space` פותח פרטים.
- **קוראי מסך**: `data-label` נקרא ככותרת שדה; ערכים עם `aria-live="polite"` לעדכונים דינמיים.

### 4. רכיבים ספציפיים בקונסולה
| מסך | טבלה נוכחית | שינוי מוצע |
|------|-------------|-------------|
| **לוח משימות** | עמודות: ID, סוג, סטטוס, עובד, זמן | כרטיס לכל משימה + באדג' סטטוס צבעוני |
| **מדדי רשת** | מטריצת מדדים רחבה | כרטיס לכל מטריקה: שם, ערך, מגמה, סף |
| **שרשרת אמת** | בלוקים עם hash, גובה, חותם | כרטיס בלוק: גובה, hash מקוצר, סטטוס אימות |
| **צי כלים** | רשימת כלים עם גרסה, סטטוס | כרטיס כלי: אייקון, שם, גרסה, פעולה אחרונה |

### 5. בדיקות קבלה (Definition of Done)
1. ✅ ב-375px (iPhone SE) — אין גלילה אופקית, כל התוכן קריא.
2. ✅ NVDA / VoiceOver — מקריאים כותרת שדה + ערך לכל שורה.
3. ✅ מקלדת בלבד — `Tab` עובר בין כרטיסים, `Enter` פותח מודל פרטים.
4. ✅ `prefers-contrast: more` — יחס ניגודיות ≥ 7:1 לטקסט, ≥ 4:1 לגבולות.
5. ✅ RTL מלא — סדר עמודות הפוך, יישור טקסט ימינה, אייקונים מותאמים.

## קבצים לעדכון (הערכה)
- `public/console.css` — הוספת media queries וכללי כרטיסים
- `public/console.js` — הוספת `data-label` דינמי בעת רינדור טבלאות
- `server/views/console.html` — הוספת `<caption>` ו-`scope` לטבלאות קיימות
- `tests/a11y/console-mobile.test.js` — בדיקות Playwright + axe-core

## מאמץ משוער
- **CSS/HTML**: 2–3 שעות
- **JS רינדור**: 1–2 שעות
- **בדיקות אוטומטיות**: 1 שעה
- **סה״כ**: ~5 שעות עבודה

## ערך מיידי
- הקונסולה הופכת שמישה בשטח (טלפון נייד במשמרת לילה).
- עמידה בתקן WCAG 2.1 AA — מפחית סיכון משפטי ומשפר שימושיות לכלל המשתמשים.
- תשתית לשיפורי נגישות עתידיים (מצב כהה, הגדלת גופן, פקודות קוליות).
