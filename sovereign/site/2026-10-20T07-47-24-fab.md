# כפתור פעולה ראשית מרחף (FAB) נגיש למסכי מגע עם משוב טקטי וקול

## כפתור פעולה ראשית מרחף (FAB) נגיש למסכי מגע

### בעיה
משתמשי המובייל ומסכי המגע בלוח-המשימות (Dispatch → Workers) נתקלים בקושי לביצוע פעולות מהירות בתנאי תנועה, רעש או אור שמש חזק. כפתורי הפעולה הראשיים ממוקמים בסרגל העליון או בתפריטים נסתרים, מה שדורש דיוק גבוה ומסיח את הדעת מהמשימה העיקרית.

### פתרון
הוספת כפתור פעולה ראשית מרחף (Floating Action Button - FAB) קבוע בפינה הימנית-תחתונה של המסך, המבצע את הפעולה הנפוצה ביותר במערכת: **יצירת משימה חדשה**.

### מאפייני הנגישות והמשוב
1. **גודל ומקום**: קוטר מינימלי 56x56 פיקסלים (לפי WCAG 2.1 touch target), מרחק מינימלי 16 פיקסלים מהקצוות.
2. **ניגוד צבעים**: יחס ניגוד מינימלי 4.5:1 מול הרקע (תומך במצבי אור שמש).
3. **משוב טקטי**: רטט קצר (haptic feedback) בלחיצה — מאשר ביצוע ללא צורך להסתכל על המסך.
4. **משוב קולי**: הודעה קולית קצרה "משימה חדשה נוצרה" (באמצעות Web Speech API או מערכת התראות קיימת) — תומך במשתמשים עם לקות ראייה או בסביבות רועשות.
5. **מצב טעינה**: אנימציית סיבוב עדינה בזמן שליחת הבקשה לשרשרת-האמת.
6. **החלפה דינמית**: אם המשימה הנפוצה משתנה (לפי נתוני /api/metrics), הכפתור מתעדכן אוטומטית (לדוגמה: ביצוע משימה ממתינה).

### איך זה עובד במערכת
- הכפתור מוטמע בלוח-המשימות כרכיב UI עצמאי, מנותק מהלוגיקה העסקית.
- הלוגיקה מאחוריו משתמשת באותו API קיים ליצירת משימה (`POST /api/tasks`), כך שאין שינוי בשרשרת-האמת או במדדים.
- המשוב הטקטי והקולי מנוהלים על-ידי שכבת נגישות קיימת (אם קיימת) או דרך אירועי דפדפן סטנדרטיים.
- אין צורך בשינוי בנתונים או במדדים — רק שכבת הצגה ואינטראקציה.

### מדדי הצלחה
- עלייה באחוז המשימות שנוצרו ממסכי מגע (מדיד דרך `/api/metrics` → `touch.created` vs `desktop.created`).
- ירידה בדיווחי תקלות מסוג "לחיצה החטאה" או "קושי ביצוע פעולה מהירה".
- משוב חיובי בסקרים קצרים אחרי שימוש (לדוגמה: "האם היה לך קל ליצור משימה תוך כדי תנועה?").

### למה זה שווה-מבט עכשיו
- גלגל-הכיוונים מציין במפורש: **שיפור-נגישות/מובייל קונקרטי**.
- המוצר כבר כולל לוח-משימות פעיל ושרשרת-אמת יציבה — הבסיס מוכן.
- אין צורך בשינוי בנתונים, במדדים או בשרשרת-האמת — רק שכבת UI בטוחה וקונספטואלית.
- זהו שיפור אחד, מדיד, בר-שימוש, שמוסיף ערך מיידי למשתמשי הקצה במצבי שימוש אמיתיים.
