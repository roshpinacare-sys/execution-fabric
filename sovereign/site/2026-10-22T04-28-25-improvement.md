# סרגל ניווט צדדי מתקפל עם קיצורי מקלדת ללוח המשימות

## הצעה: סרגל ניווט צדדי מתקפל עם קיצורי מקלדת

### הבעיה
בלוח המשימות (Dispatch → Workers) המשתמשים נאלצים להשתמש בעכבר כדי לעבור בין תצוגות שונות (כל המשימות, המשימות שלי, לפי סטטוס, לפי עדיפות), להחיל סינונים, או לגשת לקבוצות מותאמות אישית. זה מאט זרימת עבודה אינטנסיבית ומפריע לרצף הקלדה.

### הפתרון המוצע
סרגל ניווט צדדי (Sidebar) קבוע-מיקום, מתקפל, עם:

1. **קיצורי מקלדת גלויים** — כל פריט מציג את קיצור המקלדת שלו (למשל `G` `A` = כל המשימות, `G` `M` = המשימות שלי, `G` `S` = לפי סטטוס).
2. **ניווט היררכי** — קבוצות ראשיות (תצוגות, סינונים, קבוצות מותאמות) עם הרחבה/כיווץ.
3. **מצב מתקפל/מורחב** — ברירת מחדל מורחב; לחיצה על אייקון המבורגר או `Ctrl`+`B` מכווצת לאייקונים בלבד.
4. **חיפוש מהיר בתוך הסרגל** — הקלדה מתחילה סינון פריטי הניווט (Command Palette קליל).
5. **התאמה אישית** — גרירה לסידור מחדש, הוספת קיצורים מותאמים לקבוצות שמורות.

### מימוש טכני
- **רכיב React חדש**: `TaskboardSidebar` ב-`src/components/taskboard/`
- **Hook לניהול מצב**: `useSidebarState` (פתוח/סגור, פריט פעיל, מצב חיפוש)
- **מערכת קיצורים**: הרחבת `useKeyboardShortcuts` הקיים עם prefix `G` (Go) לניווט
- **CSS**: Grid layout עם `min-width: 240px` מורחב, `64px` מכווץ; מעברים חלקים (`transition: width 150ms ease`)
- **נגישות**: `role="navigation"`, `aria-label="ניווט לוח משימות"`, תמיכה מלאה ב-Tab/Enter/Escape

### קיצורי מקלדת מוצעים
| קיצור | פעולה |
|--------|--------|
| `G` `A` | כל המשימות |
| `G` `M` | המשימות שלי |
| `G` `S` | סינון לפי סטטוס |
| `G` `P` | סינון לפי עדיפות |
| `G` `G` | קבוצות מותאמות אישית |
| `Ctrl` `B` | כיווץ/הרחבת הסרגל |
| `/` (כשהפוקוס בסרגל) | חיפוש מהיר |

### מדדי הצלחה
- זמן ממוצע למעבר בין תצוגות יורד ב-≥40%
- ≥60% מהמשתמשים הפעילים משתמשים בקיצורי מקלדת תוך 30 יום
- ציון SUS (System Usability Scale) עולה ב-5 נקודות

### סיכונים ושיקולים
- **עקומת למידה**: נדרש onboarding קליל (טיפ ראשון-פעם עם אנימציה)
- **התנגשות קיצורים**: בדיקה מול קיצורים קיימים במערכת (כרגע `G` פנוי)
- **מובייל**: הסרגל מוחלף ב-Drawer תחתון ב-<768px (מחוץ לתחום ההצעה הזו)

### צעדים הבאים
1. אפיון מפורט של מבנה הנתונים (קבוצות, פריטים, קיצורים)
2. מימוש רכיב הבסיס + Hook
3. אינטגרציה עם מצב הסינון הקיים ב-Taskboard
4. בדיקות נגישות ומקלדת
5. שחרור מאחורי Feature Flag
