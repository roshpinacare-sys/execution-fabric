# מצב נגישות גבוה ללוח המשימות: ניגודיות מוגברת, פוקוס ברור וניווט מקלדת מלא

## הצעה: מצב נגישות ייעודי ללוח המשימות (Dispatch Board)

### הבעיה
לוח המשימות הנוכחי עובד היטב בעכבר/מגע, אך חסר תמיכה מלאה במשתמשי מקלדת וקוראי מסך:
- יחס ניגודיות טקסט/רקע נמוך מ-4.5:1 בכמה מצבים (כרטיסי משימה מושבתים, תגיות עדיפות).
- טבעת פוקוס דקה (`outline: 1px solid #888`) שקשה לראות על רקע כהה.
- סדר טאב לא עקבי: כפתורי פעולה בכרטיס מקבלים פוקוס לפני כותרת המשימה.
- אין קישור "דלג לתוכן ראשי" (Skip to main content).
- `aria-live` חסר לעדכוני סטטוס בזמן אמת (העברה, סיום, שגיאה).

### הפתרון המוצע
הוספת מתג **"מצב נגישות גבוה"** בהגדרות הלוח (נגיש גם ב-`Alt+A`). כשהמצב מופעל:

1. **ערכת נושא נגישה** (`data-a11y="high"` על `<html>`):
   - רקע `#0B0B0F` / טקסט ראשי `#F5F5F5` (יחס 18:1).
   - צבעי עדיפות: גבוה `#FF6B6B`, בינוני `#FFD93D`, נמוך `#6BCB77` — כולם עוברים 4.5:1 על הרקע הכהה.
   - גבולות כרטיס `2px solid #FFFFFF`.

2. **טבעת פוקוס בולטת**:
   ```css
   [data-a11y="high"] *:focus-visible {
     outline: 3px solid #FFD93D;
     outline-offset: 2px;
   }
   ```

3. **סדר טאב לוגי** בכל כרטיס משימה:
   1. כותרת המשימה (קישור/כפתור ניווט)
   2. תגית עדיפות (קריאה בלבד, `tabindex=-1`)
   3. כפתורי פעולה: הקצאה, פרטים, סגירה
   4. תפריט פעולות נוספות

4. **קישור דילוג** בראש הדף (מוסתר ויזואלית, מופיע בפוקוס):
   ```html
   <a href="#dispatch-board" class="skip-link">דלג ללוח המשימות</a>
   ```

5. **הכרזות חיות** לעדכוני סטטוס:
   ```html
   <div id="a11y-announcer" aria-live="polite" aria-atomic="true" class="sr-only"></div>
   ```
   כשמשימה משנה סטטוס → דחיפת טקסט עברי קצר ("משימה 1242 הועברה לעובד 3").

6. **תוויות ARIA** לכפתורי פעולה סמליים (סמל בלבד):
   `aria-label="הקצה משימה לעובד"`, `aria-label="סגור משימה"` וכו'.
