# לוח-יעדים שבועי — מדדי-הצלחה ויעדים כמותיים

מבנה זה מגדיר את **היעדים השבועיים** של הרשת כנתונים מובנים. כל יעד כולל:
- **metricId** — מזהה ייחודי למעקב
- **label** — שם תצוגה בעברית
- **target** — ערך היעד המספרי לשבוע
- **current** — ערך נוכחי (מתעדכן אוטומטית ממדדי-רשת)
- **weight** — משקל יחסי בחישוב הציון הכולל (סכום = 100)
- **threshold** — סף מינימלי למעבר (אזהרה אם נמוך)
- **direction** — "higher" או "lower" — כיוון השיפור הרצוי
- **source** — מקור הנתון (API endpoint)

הקובץ נועד להזנה ישירה לרכיב "לוח-יעדים" בקונסולה — ללא עיבוד נוסף.

## דוגמת שימוש בקונסולה
```js
fetch('/api/weekly-goals')
  .then(r => r.json())
  .then(data => renderGoalsDashboard(data));
```

הרכיב יציג: פס-התקדמות לכל יעד, צבע לפי מצב (ירוק/צהוב/אדום), ציון משוקלל שבועי, ומגמה מול שבוע קודם.
