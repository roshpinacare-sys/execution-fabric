# אינטגרציית כלי 'שרשרת-אמת' (Ledger) כמנגנון אימות שלמות למוצר

# הצעה: אינטגרציית כלי 'שרשרת-אמת' (Ledger) כמנגנון אימות שלמות למוצר

## הבעיה
המוצר מפעיל 10 משטחים שונים (קונסולה, לוח-משימות, מדדים, התפתחות, מפת-ריבונות, שער-העברה, קיר-צמיחה, צי-כלים, משמרת-לילה) ללא מנגנון אחיד לאימות שלמות הנתונים הזורמים ביניהם. כשלים ב-"unknown" department (25 מקרים) ו-saturated ladders מצביעים על צורך באימות שלמות חוצה-מערכת.

## הפתרון המוצע
שילוב כלי **Ledger hash-chain** (קיים ב-arsenal) כ-**Integrity Verification Layer** המשרת את כל המשטחים:

### 1. ארכיטקטורת אינטגרציה
```typescript
// lib/integrity/ledger-verifier.ts
interface IntegrityRecord {
  surface: string;
  payloadHash: string;
  prevHash: string;
  timestamp: number;
  blockHeight: number;
}

class LedgerIntegrityVerifier {
  private chain: IntegrityRecord[] = [];
  private readonly GENESIS_HASH = '0'.repeat(64);

  verifyAndAppend(surface: string, payload: unknown): IntegrityRecord {
    const payloadHash = this.hash(JSON.stringify(payload));
    const prevHash = this.chain.length > 0 
      ? this.chain[this.chain.length - 1].payloadHash 
      : this.GENESIS_HASH;
    
    const record: IntegrityRecord = {
      surface,
      payloadHash,
      prevHash,
      timestamp: Date.now(),
      blockHeight: this.chain.length
    };
    
    this.chain.push(record);
    this.persistToLedgerTool(record); // קריאה לכלי הארסנל הקיים
    return record;
  }

  verifyChain(): { valid: boolean; brokenAt?: number } {
    for (let i = 1; i < this.chain.length; i++) {
      if (this.chain[i].prevHash !== this.chain[i-1].payloadHash) {
        return { valid: false, brokenAt: i };
      }
    }
    return { valid: true };
  }

  private persistToLedgerTool(record: IntegrityRecord) {
    // אינטגרציה עם כלי ה-Ledger הקיים ב-arsenal
    // require('@arsenal/ledger').append(record)
  }

  private hash(data: string): string {
    // SHA-256 implementation
    return require('crypto').createHash('sha256').update(data).digest('hex');
  }
}
```

### 2. נקודות חיבור (Integration Points)
| משטח | מה נבדק | תדירות |
|--------|----------|----------|
| קונסולה RTL | מצב תצוגה, פקודות משתמש | כל אינטראקציה |
| לוח-משימות | הקצאות, סטטוסי workers | כל שינוי משימה |
| מדדי-רשת | מטריקות גולמיות | כל דגימה (30s) |
| התפתחות-עצמית | החלטות למידה, HIGH findings | כל אירוע למידה |
| מפת-ריבונות | ספירת צמתים, סטטוסים | כל census |
| שער-העברה | handoff payloads | כל handoff |
| קיר-צמיחה | improvements חדשות | כל הוספה |
| צי-כלים | הגדרות כלים, הרשאות | שינוי הגדרה |
| משמרת-לילה | דופק עורקים, health checks | כל מחזור (60s) |

### 3. API ציבורי למוצר
```typescript
// נחשף כ-singleton דרך DI container
const integrity = new LedgerIntegrityVerifier();

// שימוש בכל משטח:
integrity.verifyAndAppend('dispatch-board', { taskId: 't-123', status: 'ASSIGNED', worker: 'w-7' });
integrity.verifyAndAppend('metrics', { cpu: 0.73, mem: 0.41, latencyP99: 142 });

// אימות תקופתי (cron job או health endpoint)
setInterval(() => {
  const result = integrity.verifyChain();
  if (!result.valid) {
    alertIntegrityBreach(result.brokenAt);
  }
}, 60_000);
```

### 4. תועלות מדידות
- **זיהוי השחתה מיידי**: כל שינוי זדוני/באג בנתונים מתגלה תוך ≤60 שניות
- **ביקורתיות (Auditability)**: שרשרת hash-chain מלאה ניתנת לייצוא ל-compliance
- **אפס תלות חיצונית**: משתמש בכלי קיים ב-arsenal, ללא dependencies חדשים
- **כיסוי מלא**: 10/10 משטחים מכוסים במנגנון יחיד

## תוכנית יישום (3 שלבים)
1. **שבוע 1**: מימוש `LedgerIntegrityVerifier` + חיבור לכלי Ledger ב-arsenal
2. **שבוע 2**: אינטגרציה ב-5 משטחים קריטיים (dispatch, metrics, evolution, census, handoffs)
3. **שבוע 3**: כיסוי 5 המשטחים הנותרים + health endpoint `/api/integrity` + התראות
