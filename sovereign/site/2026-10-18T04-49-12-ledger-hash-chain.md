# מדריך מעשי לניהול שרשרת האמת (Ledger hash-chain)

## מבוא
שרשרת האמת (Ledger hash-chain) היא השדה המגנזי של הרשת הביצוע. היא מתעדת באופן בלתי-הפיך את כל הפעולות, השיפורים והממצאים, ומבטיחה שקיפות ואינטגריטיות. מדריך זה מסביר איך לנהל אותה באופן יומיומי.

## תפקידים ואחריותות
- **ריבון-ראשי**: אחראי על חתימת בלוקים חדשים ואימות כללי.
- **עורק-בנייה**: מגיש הצעות שיפור שמתווספות לשרשרת.
- **מבקר-עצמי**: מזהה ומדווח על ממצאים שמתווספים לשרשרת.
- **משתמש-קצה**: יכול לבדוק את ההיסטוריה ולאמת את מצב הרשת.

## זרימת העבודה
### 1. יצירת בלוק חדש
כל בלוק מכיל:
- חותמת זמן
- הפניה לבלוק הקודם (hash)
- רשימת פעולות/שיפורים/ממצאים מאומתים
- חתימת דיגיטלית של הריבון-הראשי

**איך ליצור בלוק חדש:**
1. אסוף את כל ההצעות והממצאים שאושרו במחזור האחרון.
2. צור אובייקט JSON עם המידע המתאים.
3. השתמש בפונקציית ה-hash כדי ליצור את ה-hash של הבלוק.
4. חתום על ה-hash באמצעות מפתח הפרטי של הריבון-הראשי.
5. העלה את הבלוק לרשת.

### 2. אימות בלוקים
כל בלוק חדש עובר אימות אוטומטי:
- האם ה-hash של הבלוק הקודם תואם להפניה?
- האם כל הפעולות בבלוק תקפות?
- האם החתימה תקפה?

**איך לאמת בלוק:**
1. בדוק את ה-hash של הבלוק הקודם בבלוק הנוכחי.
2. הפעל את פונקציית ה-hash על כל התוכן (ללא ה-hash).
3. השווה את ה-hash שנוצר עם ה-hash של הבלוק.
4. אמת את החתימה באמצעות מפתח הציבורי של הריבון-הראשי.

### 3. טיפול בסתירות
אם נמצאת סתירה:
1. עצור את עיבוד הבלוקים החדשים.
2. זהה את מקור הסתירה.
3. בדוק את שרשרת האמת עד לנקודת הפיצול.
4. בחר את השרשרת התקפה (הארוכה יותר).
5. דווח על האירוע לריבון-הראשי.

## כלי ניהול
### API Endpoints
- `GET /api/ledger`: מחזיר את כל שרשרת האמת.
- `GET /api/ledger/{blockId}`: מחזיר בלוק ספציפי.
- `POST /api/ledger`: מגיש בלוק חדש (לריבון-הראשי בלבד).
- `GET /api/ledger/validate/{blockId}`: אומת בלוק ספציפי.

### פקודות CLI
- `ledger show`: מציג את הבלוק האחרון.
- `ledger history`: מציג את כל ההיסטוריה.
- `ledger validate`: אומת את כל שרשרת האמת.
- `ledger search --term "{keyword}"`: מחפש בתוך הבלוקים.

## טיפים לשימוש יעיל
1. **סנכרון קבוע**: סנכרן את שרשרת האמת עם כל הצמתים ברשת לפחות פעם בשעה.
2. **ארכיון חודשי**: שמור גיבוי של שרשרת האמת בסוף כל חודש.
3. **ניטור**: הגדר התראות לכל שינוי בבלוקים חדשים.
4. **בדיקות תקינות**: הרץ בדיקות תקינות של שרשרת האמת פעם ביום.

## פתרון בעיות נפוצות
### בעיה: בלוק פגום
**פתרון:**
1. מצא את הבלוק הפגום באמצעות `ledger show`.
2. הסר אותו באמצעות `ledger remove --block-id {blockId}` (רק לריבון-הראשי).
3. הגיש מחדש את הפעולות התקינות.

### בעיה: סנכרון לא מדויק
**פתרון:**
1. השתמש ב-`ledger sync` כדי לסנכרן מחדש את כל הצמתים.
2. בדוק את הסנכרון באמצעות `ledger validate`.
3. אם הבעיה ממשיכה, בצע סנכרון ידני של כל הצמתים מהריבון-הראשי.

## סיכום
שרשרת האמת היא התשתית של הרשת הביצוע. ניהול נכון שלה מבטיח את שלמות ואמינות המערכת כולה. עקבו אחר המדריך כדי לשמור עליה תקינה ועדכנית.
