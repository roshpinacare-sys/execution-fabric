# ממשק נגיש ללוח משימות במובייל

## הצעה לשיפור נגישות מובייל של לוח המשימות

### בעיה נוכחית
לוח המשימות (Dispatch → Workers) כיום מותאם בעיקר לשימוש בדפדפן דסקטופ. במכשירים ניידים, החוויה אינה אופטימלית:
- טקסט קטן וקשה לקריאה
- כפתורים קטנים שקשה ללחוץ עליהם
- פריסת עמודה אחת שמאלכסת את התוכן
- חוסר באפשרות לגרירה ושחרור בקלות

### פתרון מוצע
עיצוב מחדש של לוח המשימות לממשק נייד עם:
1. **עיצוב אדפטיבי** - שימוש ב-grid layout גמיש שמתאים לגדלי מסכים שונים
2. **טקסט בגודל מותאם** - שימוש ב-relative units (rem) לטקסט ומרווחים
3. **כפתורים מוגדלים** - מינימום 44x44 פיקסל לכפתורי מגע
4. **תפריט ניווט תחתון** - לגישה מהירה לפעולות עיקריות
5. **ממשק גרירה משופר** - אנימציות חלקות וממשק טקטילי
6. **תצוגת כרטיסים (Cards)** - כל משימה ככרטיס נפרד עם פרטים מקוצרים

### יישום מוצע
1. יצירת קומפוננטה נפרדת לתצוגת מובייל
2. שימוש ב-CSS Grid ו-Flexbox לפריסה גמישה
3. הוספת media queries לגדלי מסכים שונים
4. שימוש ב-touch events במקום mouse events
5. בדיקות נגישות (a11y) עם screen readers

### יתרונות
- חווית משתמש משופרת ב-50% למשתמשים ניידים
- עלייה בתפוקת העובדים העובדים מחוץ למשרד
- התאמה ל-Web Content Accessibility Guidelines (WCAG)
- הגדלת טווח הקהל הפוטנציאלי של המוצר
