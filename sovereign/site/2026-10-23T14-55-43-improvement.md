# מדריך פתרון תקלות נפוצות ברשת הביצוע

## הקדמה
רשת הביצוע מתפקדת באופן עצמאי ומתמיד, אך כמו כל מערכת מורכבת, עלולות להתעורר בעיות. מדריך זה מציג את התקלות הנפוצות ביותר שנמצאו במערכת, ומספק פתרונות מעשיים לטיפול בהן, על בסיס ממצאי-HIGH שנאספו מהרשת עצמה.

## תקלה 1: חסימת משימות בלוח המשימות (Dispatch → Workers)

### תיאור התקלה
משימות נכנסות ללוח המשימות אך לא מוקצות ל-Workers, מה שגורם לעיכובים בעיבוד.

### אבחנה
1. בדוק את סטטוס ה-Workers ב-"שרשרת-אמת" (Ledger hash-chain)
2. ודא שה-Workers מוגדרים כ-ACTIVE
3. בדוק את יומני המערכת (logs) אחרי הודעות שגיאה הקשורות לקצב הקצאה

### פתרון
```bash
# הפעל פקודת אימות ואיפוס קצב הקצאה
saos-control-center --reset-dispatch-rate --verify-workers
```

## תקלה 2: איבוד חיבור למסד הנתונים

### תיאור התקלה
הרשת מאבדת את החיבור למסד הנתונים, מה שמוביל לכשלים בעדכון נתוני מדדים.

### אבחנה
1. בדוק את סטטוס החיבור בממשק הניהול
2. בדוק את נתוני הזיכרון (memory) במדדי הרשת
3. חפש הודעות שגיאה הקשורות ל-timeout או refused connection

### פתרון
```bash
# איפוס חיבור מסד הנתונים עם פרמטרי אבטחה מעודכני�ns
saos-control-center --reset-db-connection --security-protocol=TLSv1.3
```

## תקלה 3: עומס זיכרון גבוה ב-Workers

### תיאור התקלה
ה-Workers צורכים יותר זיכרון מהצפוי, מה שמאט את המערכת.

### אבחנה
1. עקוב אחר נתוני הזיכרון בפאנל הניהול
2. בדוק את סוגי המשימות שגורמות לעומס
3. בדוק את מדדי הביצועים של כל Worker

### פתרון
```bash
# הגדרת גבולות זיכרון דינמיים ל-Workers
saos-control-center --set-memory-limits --worker-max=2GB --worker-min=512MB
```

## תקלה 4: כשלים בשרשרת האמיתות (Ledger)

### תיאור התקלה
האימות של שרשרת ה-Hash מכשל, מה שמעמיד בספק את שלמות הנתונים.

### אבחנה
1. בדוק את סטטוס ה-Hash בממשק הניהול
2. השווה בין ה-Hash המקומי ל-Hash המרוחק
3. בדוק את יומני המערכת אחרי פעולות כתיבה

### פתרון
```bash
# סנכרון מחדש של שרשרת ה-Hash
saos-control-center --resync-ledger --force-consensus
```

## טיפים למניעת תקלות

1. **עדכון קבוע**: הפעל עדכונים קבועים של המערכת
2. **ניטור**: עקוב אחר מדדי הרשת באופן קבוע
3. **תכנון קיבולת**: הקצה משאבים בהתאם לצפי עומס
4. **בדיקות תקינות**: הפעל בדיקות תקינות קבועות
