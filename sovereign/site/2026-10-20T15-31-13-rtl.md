# התאמת קונסולת RTL למובייל: פריסה רספונסיבית, אזורי מגע מוגדלים וניווט מקלדת מלא

# הצעה: התאמת קונסולת RTL למובייל

## הבעיה
הקונסולה הנוכחית בנויה למסך רחב: טבלאות רחבות, כפתורים צפופים, אין נקודות שבירה (breakpoints) ואין ניווט מקלדת מלא. במכשירים צרים (< 640 px) המשתמש נאלץ לגלול אופקית, לפספס פעולות קריטיות (אישור העברה, דחייה, פתיחת פרטים) ומתקשה לעקוב אחר מיקוד המקלדת.

## הפתרון — שלושה צירים מעשיים

### 1. פריסה רספונסיבית (CSS Grid + Container Queries)
```css
/* קובץ: console-responsive.css */
@container (max-width: 639px) {
  .dispatch-grid {
    grid-template-columns: 1fr;
  }
  .task-card {
    display: grid;
    grid-template-areas:
      "header"
      "meta"
      "actions";
    gap: 0.5rem;
    padding: 1rem;
  }
  .task-header { grid-area: header; }
  .task-meta   { grid-area: meta;   font-size: 0.875rem; color: var(--muted); }
  .task-actions{ grid-area: actions; display: flex; flex-wrap: wrap; gap: 0.5rem; }
}
```
- **נקודות שבירה**: 640 px (מובייל), 1024 px (טאבלט), 1280 px (דסקטופ).
- טבלאות הופכות לכרטיסים (cards) במובייל — כל שורה = כרטיס שלם.
- סרגל צד (sidebar) הופך למגירה נפתחת (off-canvas) עם `position: fixed; inset-inline-start: 0;` התומך RTL.

### 2. אזורי מגע מוגדלים (Touch Targets ≥ 48×48 px)
```css
.action-btn {
  min-height: 48px;
  min-width: 48px;
  padding: 0.75rem 1rem;
  font-size: 1rem; /* מונע זום אוטומטי ב-iOS */
  touch-action: manipulation;
}
.action-btn:focus-visible {
  outline: 3px solid var(--focus-ring);
  outline-offset: 2px;
}
```
- כל כפתורי פעולה (אישור, דחייה, פרטים, סינון) מקבלים מחלקה `.action-btn`.
- ריווח בין כפתורים סמוכים ≥ 8 px למניעת לחיצות שגויות.

### 3. ניווט מקלדת מלא ודילוג לתוכן
```html
<!-- בתחילת <body> -->
<a href="#main-content" class="skip-link">דלג לתוכן ראשי</a>
<main id="main-content" tabindex="-1"></main>
```
```css
.skip-link {
  position: absolute;
  top: -100%;
  left: 50%;
  transform: translateX(-50%);
  padding: 0.75rem 1.5rem;
  background: var(--primary);
  color: white;
  z-index: 10000;
}
.skip-link:focus { top: 1rem; }
```
- **Tab order** לוגי: כותרת → סינון → רשימת משימות → פעולות כרטיס → פגינציה.
- `aria-roledescription="כרטיס משימה"` על כל `.task-card`.
- כפתורי פעולה מקבלים `aria-label` בעברית ("אשר העברה", "דחה העברה", "פתח פרטים").
- מצב מיקוד גלוי תמיד (`:focus-visible`) — גם במגע וגם במקלדת.

## סיכונים ותלות
- **סיכון**: Container Queries לא נתמכים בדפדפנים ישנים (לפני 2023). **פתרון**: פוליפיל `container-query-polyfill` או fallback עם `@media`.
- **תלות**: רכיבי UI קיימים חייבים לקבל `className` יציבים (`.action-btn`, `.task-card`). אם הם נוצרים דינמית — יש לעדכן את ה-renderer.
- **בדיקת רגרסיה**: להריץ Cypress/E2E על viewport 375×667 ו-768×1024.
