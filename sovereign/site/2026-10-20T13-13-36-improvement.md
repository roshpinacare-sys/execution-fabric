# הדגשת כרטיסי העברה ממתינים עם מונה שעות דביק

## הצעה: הדגשת כרטיסי העברה ממתינים עם מונה שעות דביק

### הבעיה
בקונסולת ה-RTL רשימת כרטיסי ההעברה (handoffs) מציגה רק סטטוס ונתיב. כשיש מספר בקשות ממתינות, קשה לזהות במבט מהיר איזו ממתינה הכי הרבה זמן — במיוחד כשהן נערמות מעל 12 שעות כפי שעולה מממצאי הרשת.

### הפתרון
להוסיף לכל כרטיס בסטטוס `PENDING_APPROVAL`:
1. **פס צדדי צבעוני** (4px) המשתנה לפי גיל ההמתנה:
   - 🟢 ירוק — פחות מ-2 שעות
   - 🟡 צהוב — 2–6 שעות
   - 🟠 כתום — 6–12 שעות
   - 🔴 אדום — מעל 12 שעות
2. **מונה שעות חי** (`13h`, `14h`…) בפינה הימנית-עליונה של הכרטיס, מתעדכן כל דקה דרך `setInterval` קליל בצד לקוח.
3. **Tooltip** בעת ריחוף: "ממתין 13 שעות ו-42 דקות — נוצר ב-2026-10-20 00:31".

### מימוש טכני
- **Backend** (`/api/handoffs`): להוסיף שדה `ageHours` (מספר עשרוני) לכל כרטיס ממתין — חישוב חד-פעמי בשאילתה.
- **Frontend** (רכיב `HandoffCard`):
  ```tsx
  const age = card.ageHours;
  const color = age < 2 ? 'var(--green)' : age < 6 ? 'var(--yellow)' : age < 12 ? 'var(--orange)' : 'var(--red)';
  return (
    <article className="handoff-card" style={{ borderLeft: `4px solid ${color}` }}>
      <span className="age-badge" style={{ color }}>
        {age.toFixed(1)}h
      </span>
      {/* שאר תוכן הכרטיס */}
    </article>
  );
  ```
  מונה חי: `useEffect(() => { const id = setInterval(() => setAge(a => a + 1/60), 60000); return () => clearInterval(id); }, []);
- **נגישות**: `aria-label="ממתין 13.7 שעות"` על הבאדג', ניגודיות WCAG AA לכל הצבעים.

### מדד הצלחה
- זמן זיהוי הבקשה הוותיקה ביותר ברשימה של 10+ כרטיסים: מ->30 שניות לפחות מ-3 שניות (בדיקת שימושיות פנימית).
- ירידה בזמן ממוצע לאישור בקשות >12 שעות ב-20% תוך שבועיים.

### למה עכשיו
שלוש בקשות ממתינות 13–14 שעות (ראו `worthALook`) — בדיוק הסף האדום. ההדגשה תמנע "הזדקנות" שקטה של בקשות עתידיות.
