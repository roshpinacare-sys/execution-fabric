# מדדי זרימת ערך שבועיים — תצורת JSON

מבנה נתונים סטנדרטי למעקב שבועי אחר ארבעה ממדי זרימת ערך עיקריים. כל שדה מוגדר עם יחידות, סף תקין, וכיוון רצוי — מאפשר בניית גרפים, התראות, ומגמות ללא פרשנות נוספת.

## מבנה ה-JSON

## שדות והגדרות

| שדה | תיאור | מקור נתונים אפשרי |
|------|--------|-------------------|
| `flow.leadTime` | זמן מהתחלת עבודה עד מסירה (P50/P85/P95) | שרשרת-אמת, משימות DONE |
| `flow.throughput` | פריטים שהושלמו בשבוע | משימות DONE, ספירה שבועית |
| `flow.quality.failureRate` | יחס כישלונות מסך הרצות | שרשרת-אמת: failed/done |
| `flow.quality.reworkRate` | פריטים שנדרשה בהם עבודה חוזרת | תגי rework במשימות |
| `flow.health.openHighs` | ממצאי HIGH פתוחים | `/api/evolution` openHighs |
| `flow.health.workerUtilization` | ניצולת עובדים פעילים | `/api/metrics` workers |
| `flow.health.queueDepth` | משימות ממתינות בתור | tasksByStatus RUNNING+QUEUED |
| `signals` | התראות אוטומטיות מבוססות ספים | חישוב צד-לקוח/שרת |

## הנחיות תצוגה
- **גרף מגמה**: `throughput.trend` (7 שבועות) — קו עם סף מינימום
- **מד זמן הובלה**: שלושה מחוונים (P50/P85/P95) עם קו אדום בסף
- **איכות**: שני מדי יחס (כישלון/עבודה חוזרת) — ירוק/אדום לפי סף
- **בריאות**: שלושה כרטיסים עם מצב תקין/אזהרה/קריטי
- **אותות**: רשימת התראות פעילות בלבד — לחיצה פותחת פירוט

## עדכון אוטומטי
מבנה זה תואם איסוף שבועי אוטומטי (Cron/Worker) ש:
1. שולף נתונים גולמיים מ-API הקיימים
2. מחשב אחוזונים וסכומים
3. כותב קובץ/רשומה `weekly-flow-<ISO-week>.json`
4. מעדכן היסטוריה לגרפי מגמה

אין צורך בשדות נוספים — כל הרחבה תהיה הרחבה של אובייקט קיים.
