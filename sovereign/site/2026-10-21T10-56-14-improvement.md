# דשבורד בריאות מערכת ומשמרת לילה — אינדיקטורים מרכזיים

## דשבורד בריאות מערכת ומשמרת לילה

קובץ JSON זה מרכז את האינדיקטורים החשובים ביותר למעקב בריאות המערכת בזמן אמת. מיועד לשימוש ב:
- קונסולת RTL בעברית (תצוגה תקופתית)
- endpoint `/api/metrics` (חשיפה חיצונית)
- סקריפטי ניטור אוטומטיים (alerting)
- דוח משמרת לילה יומי

### הסבר שדות

| שדה | תיאור | סף אזהרה |
|------|---------|-----------|
| `chain.successRate` | אחוז בלוקים תקינים בשרשרת | < 0.85 |
| `tasks.failureRate` | כשלונות מתוך סה"כ משימות | > 0.10 |
| `memory.deliveryRate` | נמסרו / יוצרו | < 0.65 |
| `handoffs.oldestPendingHours` | זמן המתנה מקסימלי לאישור | > 12h |
| `nightWatch.errorRate` | שגיאות במחזור לילה | > 0.05 |
| `healthScore` | ציון משוקלל כללי | < 0.75 |

### שימוש מומלץ

```bash
# בקונסולה
curl -s /api/metrics/health | jq .

# התראה אוטומטית
if (( $(jq '.healthScore < 0.75' /api/metrics/health) )); then
  alert "System health degraded: $(jq .healthScore /api/metrics/health)"
fi
```
