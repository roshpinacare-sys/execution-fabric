# מדריך מעשי להתקנת תוספי ניטור מותאמים במערכת השרשרת-האמת

מערכת השרשרת-האמת תומכת בהרחבה דרך ממשק תוספים המאפשר הוספת לוגיקת ניטור מותאמת ללא פגיעה ביציבות הליבה. המדריך הזה מציג את התהליך המלא: מהגדרת הסכמה ועד לאימות בפועל.

## 1. הבנת ממשק התוסף
כל תוסף ניטור חייב ליישם את הממשק הבא:

```typescript
interface TruthLedgerPlugin {
  id: string;                     // מזהה ייחודי (למשל: 'alert-threshold-v1')
  version: string;                // גרסה סמנטית (למשל: '1.0.0')
  activate(ledger: LedgerAPI): void;  // קריאה בעת הטעינה
  deactivate?(): void;            // אופציונלי: ניקוי בעת הסרה
  getMetrics?(): Metric[];        // אופציונלי: חשיפת מדדים מותאמים
}
```

## 2. יצירת תוסף חדש
### שלב 1: הגדרת המבנה
צור תיקייה חדשה ב-`/plugins/monitors/` עם שם התוסף (למשל: `high-value-transfer-monitor`).

בתוכה, צור את הקובץ `index.ts`:

```typescript
import { TruthLedgerPlugin, LedgerAPI, Metric, Severity } from '@saos/ledger-types';

export const plugin: TruthLedgerPlugin = {
  id: 'high-value-transfer-monitor',
  version: '1.0.0',
  activate(ledger: LedgerAPI) {
    // הרשמה לאירועי העברה
    ledger.on('transfer', (tx) => {
      if (tx.value > 10000) {  // סף של 10,000 יחידות
        ledger.log({
          type: 'ALERT',
          severity: Severity.HIGH,
          message: `העברה בעלת ערך גבוה זוהתה: ${tx.value} מ-${tx.from} ל-${tx.to}`,
          txId: tx.id,
          timestamp: new Date().toISOString()
        });
      }
    });
  },
  getMetrics() {
    return [
      {
        id: 'high-value-transfers-count',
        label: 'העברות בעלות ערך גבוה',
        value: 0,  // יוערך על-ידי הלוגיקה למעלה
        type: 'counter'
      }
    ];
  }
};

export default plugin;
```

### שלב 2: הוספת התוסף לקונפיגורציה
ערוך את קובץ `ledger.config.ts` בשורש הפרויקט:

```typescript
import { defineLedgerConfig } from '@saos/ledger-config';
import highValueMonitor from './plugins/monitors/high-value-transfer-monitor';

export default defineLedgerConfig({
  plugins: [
    highValueMonitor,
    // תוספים אחרים...
  ],
  // הגדרות אחרות...
});
```

### שלב 3: בנייה והפעלה
הרץ את הפקודות הבאות:

```bash
# בניית התוסף
npm run build:plugins

# הפעלת המערכת עם התוסף החדש
npm run start:ledger
```

## 3. אימות ותקינות
### בדיקת טעינה
לאחר ההפעלה, בדוק את הלוגים עבור:

```
[INFO] Plugin activated: high-value-transfer-monitor@v1.0.0
```

### בדיקת פעילות
שלח העברה בדיקה בערך גבוה דרך ה-API או הקונסולה ווודא כי:
- נוצר לוג מסוג `ALERT` בחומרה `HIGH`
- המדד `high-value-transfers-count` עלה ב-1

### בדיקת ניקוי (אופציונלי)
אם מימשת `deactivate`, הסר את התוסף זמנית ווודא כי אין שגיאות או זיכרון שנותר.

## 4. המלצות עבודה
- **השתמש ב-Typescript** כדי לקבל השלמה אוטומטית ובדיקת סוגים בזמן הפיתוח.
- **אל תבצע פעולות סינכרוניות ארוכות** ב-`activate` – העבר אותן ל-worker או השתמש ב-`setTimeout` אם נדרש.
- **תעד כל תוסף** בקובץ `README.md` בתיקייתו עם הסבר, סף הפעלה, ודוגמאות שימוש.
- **הגבל את ההרשאות** – תוספים אינם צריכים גישה ישירה למערכת הקבצים או משתני סביבה אלא אם כן מאושר במפורש.
