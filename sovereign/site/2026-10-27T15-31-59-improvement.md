# מדריך תפעול: הפעלת וניהול משמרת הלילה (עורקי הלב)

משמרת הלילה היא התשתית החיונית שמבטיחה את יציבותה והתפקוד של רשת-הביצוע. עורקי הלב אחראים על תזמון מדויק, ניהול זיכרון, והתאוששות מכשלים. מדריך זה מספק את ההדרכה הנדרשת לפעולה יעילה ומובנת.

## מהי משמרת הלילה?

משמרת הלילה (עורקי הלב) היא קבוצת תהליכי רקע עצמאיים, שרצים בסביבת הרשת ומבצעים פעולות קריטיות:

*   **פיקוח על עורקי הלב:** ניטור רציף של תהליכי הליבה (עורקים).
*   **ניהול זיכרון:** ניקוי זיכרון מטמון, ניהול משאבים, ומניעת דליפות.
*   **טיפול בכשלים:** איתור והתאוששות אוטומטית מכשלים ברשת.
*   **תזמון משימות:** הפעלת משימות תזמון ותחזוקה בזמנים מוגדרים.

## הפעלה ובקרה בסיסית

### 1. הצגת מצב משמרת הלילה

כדי לקבל תמונת מצב מלאה על משמרת הלילה, עליך לבצע בקשת API לנתוני המערכת:

```bash
curl -X GET "https://your-network-domain/api/heartbeat" -H "Content-Type: application/json"
```

**תשובה צפויה:**

```json
{
  "status": "active",
  "lastCheck": "2026-10-27T15:31:35.093Z",
  "processes": [
    { "name": "artery-pacer", "pid": 12345, "status": "running", "cpu": 5.2 },
    { "name": "memory-cleaner", "pid": 12346, "status": "running", "cpu": 2.1 },
    { "name": "recovery-agent", "pid": 12347, "status": "idle", "cpu": 0.0 }
  ],
  "memory": {
    "learned": 594,
    "produced": 404,
    "delivered": 373,
    "openLoops": 20
  }
}
```

### 2. הפעלה ועצירה

פעולות אלו מיועדות למנהלי מערכת מורשים בלבד.

*   **הפעלת משמרת הלילה:**
    ```bash
    sudo systemctl start network-heartbeat
    ```
*   **עצירת משמרת הלילה:**
    ```bash
    sudo systemctl stop network-heartbeat
    ```
*   **הפעלה מחדש (Restart):**
    ```bash
    sudo systemctl restart network-heartbeat
    ```
*   **בדיקת סטטוס:**
    ```bash
    sudo systemctl status network-heartbeat
    ```

## ניטור וטיפול בתקלות

### זיהוי תקלה נפוצה: עומס זיכרון גבוה

משמרת הלילה מציגה מדדים בזמן אמת. עומס זיכרון גבוה בתהליך `memory-cleaner` עלול להצביע על דליפת זיכרון.

1.  **אימות התקלה:** הרץ את פקודת המצב ובדוק את ערך `memory.learned` או ערכי ה-CPU של התהליכים.
2.  **איסוף לוגים:**
    ```bash
    journalctl -u network-heartbeat -f
    ```
    חפש הודעות שמצביעות על כשלים בניקוי זיכרון.
3.  **פעולת תיקון:**
    *   **איפוס טווח זיכרון:** הפעל מחדש את תהליך `memory-cleaner`.
        ```bash
        sudo systemctl restart network-heartbeat-memory-cleaner
        ```
    *   **דיווח לרשת:** אם התקלה חוזרת, דווח עליה למערכת הביקורת כממצא HIGH עם פרטי הלוגים.

### זיהוי תקלה נפוצה: כשל בפיקוח עורקים

תהליך `artery-pacer` אחראי על תזמון ופיקוח על כלל העורקים.

1.  **אימות התקלה:** הרץ את פקודת המצב ובדוק את סטטוס של `artery-pacer`.
2.  **איסוף לוגים:**
    ```bash
    journalctl -u network-heartbeat -f | grep "artery-pacer"
    ```
    חפש הודעות על כשלים בתזמון או בתקשורת עם עורקים אחרים.
3.  **פעולת תיקון:**
    *   **הפעלה מחדש של התהליך:**
        ```bash
        sudo systemctl restart network-heartbeat-artery-pacer
        ```
    *   **איפוס שרשרת האמת (Ledger):** במקרים קיצוניים, ייתכן צורך באיפוס השרשרת. פעולה זו דורשת התערבות של בעלי המערכת.

## ניהול קבוע

*   **בדיקות שגרה:** הפעל את בקשת ה-API למצב משמרת הלילה פעם ביום כדי לוודא כי כל התהליכים פעילים והמשאבים בטווח תקין.
*   **ניקוי לוגים:** קבע תזמון לניקוי אוטומטי של לוגי המערכת כדי למנוע מילוי דיסקים.
*   **עדכוני תצורה:** כל שינוי בקבצי התצורה של משמרת הלילה חייב לבוא לאחר גיבוי של הקבצים המקוריים.

## משאבים נוספים
