# מדריך-תפעול: אימות-אמת והחלפת-מפתח בקונסולה RTL

## אימות-אמת והחלפת-מפתח בקונסולה RTL

### רקע
שרשרת-האמת (Ledger hash-chain) היא המקור-הרשמי למצב-הדברים של כל-העסקאות והאירועים במערכת. כל-שינוי-בתוכנה-דורש-אימות-נגדה לפני-שחרור.

### שלב-1: אימות-אמת מקומי
לפני-כל-שחרור-קוד,-הרץ-את-הפקודה:
```bash
npx ledger verify --chain --since last-release
```
הפקודה-בודקת-ש-כל-ההאש-בלוקים-בתקופה-שמאז-הגרסה-הקודמת-תקינים-ולא-נוצרו-פיצולים.

### שלב-2: אימות-אמת-מרוחקת
אם-הפקודה-הצליחה-לוקלית,-אמת-גם-נגד-הצומת-הרשתי:
```bash
curl -s https://ledger-api.example.com/verify?since=last-release | jq .status
```
התשובה-צריכה-להיות `verified`.

### שלב-3: החלפת-מפתח-העברה (Hand-off Key)
כאשר-יש-לעדכן-את-מפתח-ההעברה-לגרסה-חדשה:
1. **גיבוי-מפתח-נוכחי**: `cp /etc/ledger/handoff.key /backup/handoff-$(date +%s).key`
2. **ייצור-מפתח-חדש**: `ledger generate-key --output /etc/ledger/handoff.key`
3. **עדכון-מפתח-בצמתים**: `ledger distribute-key --target all --new-key /etc/ledger/handoff.key`
4. **אימות-לאחר-החלפה**: `npx ledger verify --chain --since key-rotation`
