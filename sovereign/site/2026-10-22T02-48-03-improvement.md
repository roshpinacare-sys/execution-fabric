# ממשק הפעלה מאוחד לכלי הארסנל דרך תפריט הקשר חכם

# הצעה: תפריט הקשר חכם להפעלת כלי הארסנל

## הבעיה
כיום כלי הארסנל זמינים רק דרך API נפרד (`/api/arsenal`) או ממשק ייעודי. משתמשים צריכים לעבור הקשר, לזכור שמות כלים, ולמלא פרמטרים ידנית — חיכוך גבוה שמונע שימוש יומיומי.

## הפתרון
תפריט הקשר (Context Menu) חכם שמופיע בלחיצה ימנית / לחיצה ארוכה על כל אלמנט במוצר:

### 1. זיהוי הקשר אוטומטי
- **משימה בטבלה** → מציג: "הרץ מחדש", "נתח כשל", "צור משימת-המשך", "ייצא ללוג"
- **בלוק בשרשרת-אמת** → מציג: "אמת חתימה", "הצג היסטוריה", "השווה לגרסה קודמת"
- **מדד בדשבורד** → מציג: "חקור אנומליה", "הגדר התראה", "ייצא CSV"
- **עובד ברשימה** → מציג: "בדוק בריאות", "הפעל אבחון", "שלח הודעה"

### 2. תצוגה מקדימה של פרמטרים
לפני הרצה — מודל קטן מציג:
- פרמטרים נדרשים (עם ערכי ברירת-מחדל חכמים)
- הערכת זמן הרצה
- השפעה צפויה (קריאה בלבד / משנה מצב)
- כפתור "אישור והרצה" / "ביטול"

### 3. הרצה אסינכרונית עם משוב
- ספינר זעיר לצד הפריט בזמן הרצה
- טוסט הצלחה/כשל עם קישור לתוצאה מלאה
- היסטוריה מקומית (Last 5) נגישה מתפריט המשתמש

## מימוש טכני
```typescript
// Hook כללי
function useArsenalContextMenu(target: ContextTarget) {
  const [menuItems, setMenuItems] = useState<ArsenalTool[]>();
  
  useEffect(() => {
    // קריאה חד-פעמית לקבלת כלים רלוונטיים
    fetch(`/api/arsenal/context?type=${target.type}&id=${target.id}`)
      .then(r => r.json())
      .then(setMenuItems);
  }, [target]);
  
  return menuItems;
}
```

**API חדש**: `GET /api/arsenal/context?type=task|block|metric|worker&id=...`
מחזיר מערך כלים עם: `id`, `label`, `description`, `params[]`, `estimatedMs`, `mutatesState`.

## מדדי הצלחה
- **אימוץ**: ≥30% מהמשתמשים הפעילים מפעילים ≥1 כלי/שבוע דרך התפריט
- **מהירות**: זמן ממוצע מזיהוי צורך → הרצה < 15 שניות
- **איכות**: <5% ביטולים אחרי פתיחת תצוגה מקדימה

## סיכונים ותשובות
| סיכון | מענה |
|-------|-------|
| עומס ויזואלי | תפריט מינימליסטי, רק כלים רלוונטיים (מקס' 5) |
| הרצה בטעות | שלב אישור חובה לפעולות משנות-מצב |
| תחזוקת מיפוי הקשר→כלים | קונפיגורציה מרכזית ב-`/config/arsenal-context-map.json` |

## צעדים הבאים
1. עיצוב רכיב `ArsenalContextMenu` (Storybook)
2. מימוש API הקשר בשרת
3. אינטגרציה ראשונית בטבלת משימות (Dispatch)
4. הרחבה לשאר המשטחים
