# הנגשת קונסולת RTL למובייל: נקודות מגע, ניווט מקלדת ומצב ניגודיות גבוה

# הצעה: הנגשת קונסולת RTL למובייל

## הבעיה
הקונסולה הנוכחית בנויה ל‑Desktop RTL. במובייל:
- כפתורים וקישורים קטנים מ‑48×48dp → שגיאות מגע.
- אין מיפוי `Tab`/`Shift+Tab`/`Enter`/`Esc` עקבי → משתמשי מקלדת חיצונית/קוראי מסך נתקעים.
- צבעי ברירת‑מחדל לא עומדים ב‑WCAG AA בניגודיות (טקסט אפור על רקע כהה).
- גלילה אופקית נסתרת בטבלאות רחבות → אובדן הקשר.

## הפתרון המוצע (שלושה צעדים מדידים)

### 1. נקודות מגע (Touch Targets)
- **כלל**: כל רכיב אינטראקטיבי (כפתור, קישור, טאב, תפריט נפתח, כרטיס לחיץ) מקבל `min-height: 48px; min-width: 48px;` + `padding: 12px 16px;`.
- **יישום**: הוספת utility class `.touch-target` ל‑CSS הגלובלי והחלה על `.btn`, `.nav-link`, `.tab`, `.dropdown-toggle`, `.card-action`.
- **בדיקה**: `npm run test:a11y` עם axe‑core — 0 הפרות `touch-target-size`.

### 2. ניווט מקלדת מלא (Keyboard Navigation)
| רכיב | מקש צפוי | התנהגות RTL |
|-------|-----------|---------------|
| סרגל ניווט עליון | `Tab` / `Shift+Tab` | סדר מימין לשמאל | 
| תפריט נפתח (hamburger) | `Enter` / `Space` | פתיחה/סגירה, פוקוס לפריט ראשון | 
| טבלאות נתונים | `Tab` נכנס לטבלה, `ArrowRight/Left` בין תאים | כיוון חיצים הפוך (Right = קודם) | 
| מודלים/טוסטים | `Esc` סוגר, `Tab` לכוד בתוך המודל | זהה | 
- **יישום**: הוספת `tabindex`, `role`, `aria-expanded`, `aria-controls` ב‑React components הרלוונטיים.
- **בדיקה**: ניווט ידני + `@testing-library/user-event` — 100% כיסוי תרחישים בטבלה.

### 3. מצב ניגודיות גבוה (High Contrast Mode)
- **מתג**: כפתור קבוע בפינה שמאלית‑עליונה (ב‑RTL זה ימין‑עליון) `data-a11y-contrast-toggle`.
- **CSS**: משתני צבע חדשים `--fg-high`, `--bg-high`, `--border-high` המופעלים ע"י class `.high-contrast` על `<html>`.
- **ערכים** (WCAG AAA):
  ```css
  :root.high-contrast {
    --fg-high: #ffffff;
    --bg-high: #000000;
    --border-high: #ffff00;
    --muted-fg: #cccccc;
  }
  ```
- **שמירה**: העדפה נשמרת ב‑`localStorage['a11y-contrast']` ומחזירה בטעינה.
- **בדיקה**: `npm run test:contrast` — יחס ניגודיות ≥ 7:1 לכל טקסט.

## קבצים שיושפעו (רשימה חלקית)
- `src/styles/global.css` — utility classes & custom properties
- `src/components/Navbar.tsx` — hamburger keyboard handling
- `src/components/DataTable.tsx` — RTL arrow navigation
- `src/components/Modal.tsx` — focus trap
- `src/hooks/useHighContrast.ts` — hook חדש לניהול מצב
- `src/App.tsx` — הפעלת class על `<html>` בתחילת הריצה

## קריטריוני קבלה (Definition of Done)
1. **Touch**: 0 הפרות `touch-target-size` ב‑axe.
2. **Keyboard**: כל זרימה ראשית ניתנת להפעלה במקלדת בלבד ב‑Chrome + Safari iOS.
3. **Contrast**: מצב גבוה עובר `npm run test:contrast` (יחס ≥ 7:1).
4. **רגרסיה**: כל הבדיקות הקיימות עוברות (`npm test`).
