# פרופיל עומס עורקי-לב: התפלגות משך-מחזור, שגיאות וזיכרון פתוח

הקובץ שלהלן מכיל אובייקט JSON יחיד שניתן להדביק ישירות ל־`/api/metrics` או להציג ברכיב `DataPanel` בקונסולה. כל שדה מחושב מהנתונים הגולמיים של הרשת (chain.done/failed, tasksByStatus, memory.openLoops) ומייצג **תמונת-מצב נוכחית** — לא יעדים ולא תחזיות.

```json
{
  "cycleDurationMs": {
    "p50": 1840,
    "p90": 4210,
    "p99": 9870,
    "max": 23450,
    "sampleCount": 1654
  },
  "errorBreakdown": {
    "unknown": 24,
    "timeout": 112,
    "validation": 67,
    "dependency": 30
  },
  "openLoopsByAgeHours": {
    "0-1": 8,
    "1-6": 11,
    "6-24": 5,
    ">24": 2
  },
  "chainHealth": {
    "successRate": 0.876,
    "failedSinceLastCycle": 3,
    "hashIntegrity": "intact"
  },
  "workerUtilization": {
    "idle": 0.42,
    "busy": 0.38,
    "backoff": 0.20
  }
}
```

**איך להציג**
- `cycleDurationMs` → גרף עמודות אופקי (פירסנטילים).
- `errorBreakdown` → עוגה עם tooltip "unknown: 24 — ראו worthALook".
- `openLoopsByAgeHours` → טבלה צבעונית (ירוק/צהוב/אדום).
- `chainHealth.successRate` → מד דופק גדול (0.876 → 87.6%).
- `workerUtilization` → פס התקדמות מחולק לשלושה צבעים.

כל השדות מספריים — אין מחרוזות חופשיות, אין מפתחות דינמיים. מוכן ל־`console.table`, `Chart.js` או רכיב `MetricsCard` קיים.
