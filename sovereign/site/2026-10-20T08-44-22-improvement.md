# לוח-מחוונים: בריאות שרשרת-אמת וצווארי-בקבוק העברות

לוח-המחוונים מרכז את ארבעת סימני-החיים הקריטיים של הריבונות:
1. **שרשרת-אמת** — יחס הצלחה/כשל מצטבר ומגמה יומית.
2. **התפלגות כשלים** — פילוח לפי מחלקה (department) לזיהוי "unknown" וריכוזי-כשל אחרים.
3. **תור העברות** — פריטים ממתינים לאישור ריבוני עם זמן-המתנה.
4. **מדדי זרימה** — throughput, זמן-מחזור ממוצע, ו-backlog פתוח.

הקובץ הבא הוא payload JSON תקני שהקונסולה יכולה לצרוך ישירות (ללא עיבוד נוסף). כל השדות מחושבים מראש — הקונסולה רק מציגה.
