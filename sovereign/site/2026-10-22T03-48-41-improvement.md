# דשבורד בריאות רשת ומשמרת לילה

מבנה נתונים זה נועד לתצוגה בקונסולת RTL העברית, בלוח המשימות, ובכל צרכן חיצוני של `/api/metrics`. הוא מרכז את **אינדיקטורי הבריאות הקריטיים** ואת **מצב משמרת הלילה** במבנה אחד, עקבי, ובר-פרסינג.

## עקרונות עיצוב
- **מקור אמת יחיד**: כל השדות נגזרים ממצב הרשת הנוכחי (chain, tasks, memory, openHighs)
- **ספי אזהרה מובנים**: כל מדד כולל `threshold` ו-`status` מחושב (ok/warn/critical)
- **מוכן ל-WebSocket**: מבנה שטוח, ללא אובייקטים מקוננים עמוקים — אידיאלי לעדכוני push
- **לוקליזציה מובנית**: תוויות בעברית מוכנות לתצוגה מיידית

## שימוש
```js
// דוגמת צריכה בקונסולה
fetch('/api/metrics/health-dashboard').then(r => r.json()).then(renderHealthDashboard)
```

### שדות עיקריים
| שדה | סוג | תיאור |
|------|------|----------|
| `timestamp` | ISO8601 | זמן יצירת הסנאפשוט |
| `systemHealth` | object | מדדים מערכתיים כוללים |
| `nightShift` | object | סטטוס משמרת לילה מפורט |
| `alerts` | array[] | איתותים פעילים המחייבים תשומת לב |
| `trends` | object | מגמות 24h/7d למדדים מרכזיים |

כל אובייקט מדד מכיל: `value`, `unit`, `threshold`, `status`, `labelHe`, `trend`
