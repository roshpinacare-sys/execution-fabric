# כרטיס 'שרשרת-אמת' אינטראקטיבי: תצוגה חיה, סינון וסימון תקלות בקונסולה RTL

# הצעה: כרטיס 'שרשרת-אמת' אינטראקטיבי

## הבעיה
כרטיס 'שרשרת-אמת' בקונסולה RTL מציג כיום רק ספירות מצטברות (`done: 2445`, `failed: 431`). אין דרך:
- לראות את הרשומות האחרונות בזמן אמת
- לסנן לפי סוג כשל (`unknown`, `timeout`, `validation` וכו')
- לסמן רשומה ספציפית לחקירה מעמיקה
- לייצא נתונים לניתוח חיצוני

בינתיים, 25 כשלים מסוג `unknown` מרוכזים (ראו `worthALook[0]`) — ואין כלי מהיר לבודד אותם.

## הפתרון המוצע
להחליף את תצוגת הספירות בטבלה אינטראקטיבית בתוך אותו כרטיס, עם יכולות:

### 1. טבלה חיה (Live Table)
- עמודות: `Hash`, `Timestamp`, `Type`, `Status`, `Severity`, `Tags`, `Actions`
- 50 רשומות אחרונות, מתעדכנת כל 10 שניות דרך `/api/ledger/recent?limit=50`
- סימון שורה ב-hover, הדגשת כשלים באדום

### 2. סינון ומיון
- תיבת חיפוש טקסט חופשי (על Hash, Tags, Error message)
- Select לסינון `Status`: `ALL | DONE | FAILED`
- Select לסינון `Type`: `ALL | UNKNOWN | TIMEOUT | VALIDATION | ...` (נגזר דינמית מהנתונים)
- מיון לפי `Timestamp` (ברירת מחדל: יורד)

### 3. פעולות שורה (Row Actions)
| אייקון | פעולה | תיאור |
|--------|--------|---------|
| 🔍 | **חקירה** | פותח מודל עם פרטים מלאים + לוגים + כפתור "סמן ל-HIGH" (כותב לממצאי-ביקורת) |
| 📋 | **העתק Hash** | מעתיק ללוח |
| 🏷️ | **הוסף תג** | מאפשר להוסיף תג ידני (למשל `investigating`, `false-positive`) — נשמר ב-localStorage ומוצג בטבלה |

### 4. ייצוא וכלים
- כפתור **ייצוא CSV** — מוריד את הטבלה המסוננת כרגע
- כפתור **רענון ידני** — מבקש מיידי מהשרת
- אינדיקטור מצב חיבור: 🟢 חי / 🟡 ממתין / 🔴 מנותק

### 5. נגישות ו-RTL
- טבלה עם `role="grid"`, ניווט מקלדת מלא (Tab, חיצים, Enter לחקירה)
- כותרות בעברית, כיוון RTL טבעי
- ניגודיות WCAG AA

## למה זה שווה
- **ערך מיידי**: 25 כשלי `unknown` ניתנים לבידוד ב-2 קליקים במקום חפירה בלוגים
- **ללא שבירה**: משתמש באותו Slot של כרטיס קיים, אותו CSS Grid, אותו מנגנון הרשאות
- **יסוד לעתיד**: אותו רכיב `LedgerTable` ישמש גם בכרטיס "משימות שנכשלו" ו"ביקורות פתוחות"
- **תואם כיוון הגלגל**: PROPOSAL — שיפור-UX קונקרטי לכרטיס-קיים בקונסולה
