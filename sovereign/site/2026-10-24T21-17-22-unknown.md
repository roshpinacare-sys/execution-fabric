# מדריך מעשי: אבחון ותיקון כשלים מסוג 'unknown' בשרשרת-האמת

> **מטרה**: להפוך 25 רשומות `unknown` לכשלים מתויגים, בעלי סיבה-שורש ברורה ופעולת-מניעה — תוך 30 דקות עבודה בקונסולה.

---

## 1. שליפת הרשומות הגולמיות (הרצה חד-פעמית)
```bash
# בקונסולה RTL → שרשרת-אמת → "הרצת שאילתה"
curl -s "http://localhost:3000/api/ledger/query?status=FAILED&department=unknown&limit=25" \
  | jq '.entries[] | {hash, timestamp, taskId, payload, error}' > unknown_failures.json
```
**פלט צפוי**: קובץ JSONL עם 25 אובייקטים — כל אחד מכיל `hash` (לשרשור), `taskId` (לשיוך למשימה), `payload` (הקלט המקורי), `error` (מחרוזת השגיאה המלאה).

---

## 2. סיווג אוטומטי ראשוני (סקריפט חד-פעמי)
```python
# classify_unknown.py — הרץ מקומית או ב-Worker ייעודי
import json, re, sys
from collections import Counter

PATTERNS = [
    (r"timeout|deadline exceeded|context deadline", "timeout"),
    (r"connection refused|ECONNREFUSED|dial tcp", "network"),
    (r"permission denied|EACCES|unauthorized|403", "auth"),
    (r"not found|404|no such file", "missing_resource"),
    (r"validation|schema|invalid input|malformed", "validation"),
    (r"rate limit|429|too many requests", "rate_limit"),
    (r"OOM|memory|alloc", "resource_exhaustion"),
    (r"panic|segfault|signal", "crash"),
]

def classify(err: str) -> str:
    err_l = err.lower()
    for pattern, label in PATTERNS:
        if re.search(pattern, err_l):
            return label
    return "unclassified"

with open("unknown_failures.json") as f:
    for line in f:
        rec = json.loads(line)
        rec["classified"] = classify(rec.get("error", ""))
        print(json.dumps(rec, ensure_ascii=False))
```
```bash
python3 classify_unknown.py > classified.jsonl
```
**תוצאה**: כל רשומה מקבלת שדה `classified` — אחד מ-`timeout|network|auth|missing_resource|validation|rate_limit|resource_exhaustion|crash|unclassified`.

## 3. טבלת סיכום לסקירת-בעלים (העתק לקונסולה → "קיר-הצמיחה")
| סיווג | כמות | דוגמת `taskId` | פעולת-מניעה מיידית |
|--------|-------|------------------|------------------------|
| timeout | *N* | `task_7f3a` | הגדל `deadline` ב-Worker הרלוונטי; הוסף retry עם backoff |
| network | *N* | `task_9b1c` | בדוק health-check של השירות הנקרא; הוסף circuit-breaker |
| auth | *N* | `task_2d4e` | רענן token/secret; ודא הרשאות ב-IAM |
| missing_resource | *N* | `task_5a8f` | הוסף בדיקת קיום לפני הרצה; צור fallback |
| validation | *N* | `task_3c7b` | הקשח סכימת קלט ב-Dispatch; החזר שגיאה ברורה ללקוח |
| rate_limit | *N* | `task_1e9d` | הטמע token-bucket ב-Worker; תאם quota עם ספק חיצוני |
| resource_exhaustion | *N* | `task_6f2a` | הגבל concurrency; הוסף monitoring זיכרון/CPU |
| crash | *N* | `task_4b8e` | אסוף stack trace; פתח issue עם `hash` שרשרת |
| unclassified | *N* | `task_0a1b` | **דורש חקירה ידנית** — ראה שלב 4 |

> מלא את העמודות *N* ו-`taskId` מתוך `classified.jsonl` (פקודה: `jq -r '.classified' classified.jsonl | sort | uniq -c`).

---

## 4. חקירת `unclassified` (מקסימום 5 דקות לרשומה)
לכל רשומה שנותרה `unclassified`:
1. פתח את ה-`hash` בשרשרת-אמת → צפה ב-`payload` המלא וב-`error` הגולמי.
2. הרץ את ה-`taskId` ידנית ב-Worker הרלוונטי עם `DEBUG=1`.
3. תעד את הסיבה האמיתית בעמודה "הערות" בטבלה לעיל.
4. עדכן את הסיווג ב-`classified.jsonl` והרץ שוב את ספירת הסיכום.

---

## 5. תיוג מחדש בשרשרת-האמת (אצווה אחת)
```bash
# tag_fix.sh — הרץ לאחר אימות הטבלה
jq -c 'select(.classified != "unclassified")' classified.jsonl | while read rec; do
  hash=$(echo $rec | jq -r .hash)
  dept=$(echo $rec | jq -r .classified)
  curl -X PATCH "http://localhost:3000/api/ledger/entry/$hash" \
    -H "Content-Type: application/json" \
    -d "{\"department\": \"$dept\", \"resolution\": \"reclassified-from-unknown\"}"
done
```
**אימות**: `curl -s "http://localhost:3000/api/ledger/query?status=FAILED&department=unknown" | jq '.count'` — צריך להחזיר `0`.
