# מנגנון אימות אוטומטי להעברות קוד ממתינות

## הבעיה
כרגע יש 3 הצעות העברה ממתינות לאישור כבר 6 שעות. כל אחת דורשת בדיקה ידנית של בעל הריבונות — תהליך איטי ומועד לטעויות.

## הפתרון המוצע
שכבת אימות אוטומטית שמריצה על כל הצעת העברה:

### 1. סריקת אבטחה סטטית (SAST)
- זיהוי prototype pollution (רלוונטי ל-lodash)
- איתור הזרקות קוד, XSS, path traversal
- בדיקת תלויות פגיעות (npm audit אוטומטי)

### 2. בדיקות איכות קוד
- הרצת linter (ESLint/TypeScript strict)
- בדיקת כיסוי בדיקות מינימלי (80%+)
- איתור console.log, debugger, TODO במצב production

### 3. ולידציית תצורה
- בדיקת תקינות package.json, tsconfig.json
- וידוא גרסאות תלויות תואמות (peerDependencies)
- בדיקת סקריפטי build/test עוברים

### 4. דוח אימות מאוחד
כל הצעה מקבלת תג סטטוס:
- ✅ **עבר** — מוכן לאישור ריבוני מיידי
- ⚠️ **אזהרות** — דורש תשומת לב, אבל ניתן לאישור
- ❌ **נכשל** — חסום אוטומטית, חוזר למפתח עם פירוט

## מימוש טכני
```typescript
// arsenal/validators/handoff-validator.ts
export async function validateHandoff(proposal: HandoffProposal): Promise<ValidationReport> {
  const results = await Promise.all([
    runSAST(proposal.files),
    runQualityChecks(proposal.files),
    runConfigValidation(proposal.files),
    runDependencyAudit(proposal.manifest)
  ]);
  return aggregateResults(results);
}
```

## אינטגרציה עם ארסנל הכלים
- שימוש ב-`saos-dex/fabric` כמנוע סריקה
- ניצול `winston-elasticsearch` ללוגינג תוצאות
- חיבור לשרשרת-אמת לרישום תוצאות אימות (hash-chain)

## תועלת מדידה
- **זמן המתנה**: 6 שעות → דקות (אימות אוטומטי מיידי)
- **סיכון אבטחה**: אפס העברות לא מאומתות מגיעות לאישור
- **עומס ריבוני**: רק הצעות שעברו סף איכות מגיעות להחלטה

## קריטריוני קבלה
1. כל הצעה חדשה עוברת אימות אוטומטי תוך < 2 דקות
2. דוח אימות מוצג לצד ההצעה בממשק השער
3. הצעות שנכשלו לא מופיעות בתור האישור הריבוני
4. לוג אימות נרשם בשרשרת-אמת לביקורת עתידית
