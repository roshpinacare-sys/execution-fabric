# מדריך תפעול: קונסולת RTL בעברית

קונסולת ה-RTL (Right-to-Left) בעברית היא הממשק הראשי של הריבון לניטור, בקרה ותפעול הרשת האוטונומית. מדריך זה מכסה את כל הנדרש לעבודה יומית יעילה.

---

## 1. מבנה המסך ואזורי תצוגה

```
┌─────────────────────────────────────────────────────────────┐
│  כותרת: סטטוס רשת | מחזור נוכחי | בריאות שרשרת           │
├──────────────┬──────────────────────────────────────────────┤
│              │                                              │
│  תפריט צד    │           אזור תוכן ראשי                    │
│  (ניווט)     │  (לוח משימות / שרשרת אמת / מדדים / ...)   │
│              │                                              │
├──────────────┴──────────────────────────────────────────────┤
│  שורת סטטוס: חיבורים | תור פעיל | התראות | שעון מחזור      │
└─────────────────────────────────────────────────────────────┘
```

### אזורי מפתח

| אזור | תפקיד | אינטראקציה עיקרית |

| **תפריט צד** | ניווט בין משטחי המוצר | מקלדת / עכבר |
| **אזור תוכן** | תצוגה אינטראקטיבית של המשטח הנבחר | תלוי משטח |
| **שורת סטטוס** | מדדים חיים והתראות | קריאה בלבד, קליק על התראה פותח פרטים |

| קיצור | פעולה | הקשר |
|---------|--------|-------|
| `Alt + 1` | עבור ללוח המשימות | גלובלי |
| `Alt + 2` | עבור לשרשרת האמת | גלובלי |
| `Alt + 3` | עבור למדדי רשת | גלובלי |
| `Alt + 4` | עבור להתפתחות עצמית | גלובלי |
| `Alt + 5` | עבור למפת הריבונות | גלובלי |
| `Alt + 6` | עבור לשער העברה לגיט | גלובלי |
| `Alt + 7` | עבור לקיר הצמיחה | גלובלי |
| `Alt + 8` | עבור לצי הכלים | גלובלי |
| `Alt + 9` | עבור למשמרת לילה | גלובלי |
| `Ctrl + R` | רענון ידני של המשטח הנוכחי | גלובלי |
| `Ctrl + F` | חיפוש בתוך המשטח הנוכחי | תלוי משטח |
| `Esc` | סגור מודל/תפריט פתוח / בטל בחירה | גלובלי |

> **הערה RTL**: בקונסולה עברית, `←` נע ימינה (קדימה) ו-`→` נע שמאלה (אחורה) בטבלאות ורשימות אופקיות.

## 3. זרימות עבודה יומיות מומלצות

### 3.1 פתיחת יום — "בוקר טוב רשת" (5 דקות)

1. **פתח קונסולה** → ודא שהכותרת העליונה מראה "בריאות שרשרת: תקין" (ירוק)
2. **`Alt + 1`** → לוח משימות: סרוק תורים — האם יש משימות `PENDING` מעל 10? → הקצה/תעדף
3. **`Alt + 2`** → שרשרת אמת: בדוק `failed` אחרונים — האם יש דפוס `unknown`?
4. **`Alt + 3`** → מדדי רשת: ודא `uptime > 99.5%`, `p95 latency < 200ms`
5. **`Alt + 6`** → שער העברה: בדוק הצעות ממתינות לאישור (כרגע: 3 פתוחות)
6. **`Alt + 7`** → קיר צמיחה: סרוק שיפורים חדשים מהלילה

### 3.2 במהלך היום — ניטור שוטף

- **כל 30 דקות**: `Ctrl + R` לרענון, הצצה לשורת סטטוס — התראות אדומות?
- **על התראה קולית/וויזואלית**: `Alt + מספר` רלוונטי → חקור → פעל
- **לפני פריסה/אישור העברה**: `Alt + 6` → קרא פרטים מלאים → אשר/דחה עם נימוק

### 3.3 סגירת יום — "לילה טוב רשת" (3 דקות)

1. **`Alt + 1`** → ודא שאין משימות `IN_PROGRESS` תקועות מעל שעה
2. **`Alt + 2`** → אשר ששרשרת האמת מסונכרנת (בלוק אחרון < 2 דקות)
3. **`Alt + 8`** → צי כלים: בדוק גיבויים אחרונים הצליחו
4. **רשום הערה** ביומן תפעולי (אם קיים) על אירועים חריגים

## 4. פקודות נפוצות לפי משטח

### לוח משימות (`Alt + 1`)

| פעולה | מקש/כפתור | הערות |
|--------|------------|--------|
| סינון לפי סטטוס | `F` → הקלד סטטוס | `PENDING`, `IN_PROGRESS`, `DONE`, `FAILED` |
| הקצאת משימה לעובד | בחר שורה → `A` → בחר עובד | דורש עובד זמין |
| עדכון עדיפות | בחר שורה → `P` → `1-4` | 1=קריטי, 4=נמוך |
| צפייה בלוגי משימה | בחר שורה → `L` | נפתח במודל |
| ייצוא תור נוכחי | `E` → בחר פורמט | CSV/JSON |

### שרשרת אמת (`Alt + 2`)

| פעולה | מקש/כפתור | הערות |
|--------|------------|--------|
| חיפוש לפי האש | `H` → הדבק האש | חיפוש מדויק |
| סינון כשלים | `F` → `failed` | מציג רק רשומות כושלות |
| פרטי בלוק | בחר שורה → `Enter` | מודל עם האש, חתימה, מטען |
| אימות שרשרת מקומי | `V` | מריץ אימות מקומי על המסך |

### שער העברה לגיט (`Alt + 6`)

| פעולה | מקש/כפתור | הערות |
|--------|------------|--------|
| צפייה בפרטי הצעה | בחר שורה → `Enter` | קוד diff, בדיקות, מטא-דאטה |
| אישור הצעה | בחר שורה → `Y` | דורש נימוק (מודל) |
| דחיית הצעה | בחר שורה → `N` | דורש נימוק (מודל) |
| בקשת מידע נוסף | בחר שורה → `I` | שולח שאלה למגיש |

## 5. פתרון תקלות נפוצות

### 5.1 הקונסולה לא מתרעננת / נתקעה

| סימפטום | סיבה אפשרית | פעולה |
|-----------|----------------|--------|
| שורת סטטוס קפואה, אין עדכונים | ניתוק WebSocket | `Ctrl + R` → אם לא עוזר: רענן דפדפן (`F5`) |
| תוכן לא מופיע באזור ראשי | שגיאת JS / API 5xx | פתח DevTools (F12) → Console → חפש שגיאות אדומות |
| ניווט מקלדת לא מגיב | פוקוס תקוע במודל | `Esc` × 2 → `Tab` להחזרת פוקוס |

### 5.2 בעיות RTL ספציפיות

| בעיה | פתרון |
|-------|--------|
| טקסט הפוך בתאים מסוימים | בדוק `dir="auto"` על האלמנט — דווח כבאג אם חוזר |
| סדר עמודות הפוך בטבלה | הגדרות טבלה → "כיוון RTL" → הפעל/כבה |
| קיצורי מקלדת הפוכים (`←`/`→`) | זה תקין ל-RTL — ראה הערה בסעיף 2 |

### 5.3 כשלי "unknown" בשרשרת האמת

> ראה גם: "לקחים מעשיים: ניהול כשלי \"unknown\" בשרשרת-האמת" בקיר הצמיחה.

1. `Alt + 2` → סנן `failed` + חפש `unknown`
2. לכל כשל: פתח פרטים → העתק `error_context`
3. הרץ אימות מקומי (`V`) על הבלוק הבעייתי
4. אם חוזר על עצמו: תייג כ"דפוס" ודווח בצי הכלים (`Alt + 8`)
