# ממשק משימות מותאם למסכים קטנים

### הצעה לשיפור נגישות במובייל

#### מה צריך לשנות?
לוח המשימות הנוכחי אינו מותאם כראוי למסכים קטנים, מה שמקשה על משתמשים במכשירים ניידים לנהל משימות ביעילות. ההצעה היא לעצב מחדש את הפריסה והאינטראקציה של לוח המשימות כדי לשפר את השימוש במובייל.

#### למה זה חשוב?
- **נגישות משופרת**: משתמשים יוכלו לנהל משימות בקלות גם במסכים קטנים.
- **חוויית משתמש**: הפחתת צורך בזום ובגלילה מיותרת.
- **יעילות**: הגדלת שיעור ההשלמה של משימות במכשירים ניידים.

#### איך זה ייראה?
1. **פריסה רספונסיבית**:
   - עמודות יתכווצנות לעמודה אחת במסכים קטנים.
   - כרטיסי משימות ישנו את גודלם וסדרם באופן אוטומטי.

2. **מחוות מגע משופרות**:
   - כפתורי הפעולה (סיום, עריכה, מחיקה) יהיו גדולים יותר וקלים להפעלה.
   - הוספת אנימציות מעבר ברורות בין מצבים שונים.

3. **סרגל כלים מתכנס**:
   - במסכים קטנים, סרגל הכלים יוצג כתפריט המתכנס (hamburger menu) כדי לחסוך מקום.

#### טיוטת קוד להתחלה:
```javascript
// התאמת פריסה למסכים קטנים
const mediaQuery = window.matchMedia('(max-width: 768px)');

function handleTaskLayoutChange(e) {
  const taskBoard = document.getElementById('task-board');
  if (e.matches) {
    taskBoard.classList.add('mobile-layout');
  } else {
    taskBoard.classList.remove('mobile-layout');
  }
}

mediaQuery.addListener(handleTaskLayoutChange);
handleTaskLayoutChange(mediaQuery);
```

#### צעדי ביצוע:
1. עיצוב מחדש של ה-CSS עבור פריסה רספונסיבית.
2. הוספת אירועי מגע משופרים למכשירים ניידים.
3. בדיקות תאימות על סוגים שונים של מכשירים ניידים.
4. אספקת משוב למשתמשים לאחר השינויים.
