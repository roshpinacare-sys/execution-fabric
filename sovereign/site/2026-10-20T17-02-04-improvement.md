# שילוב ממשק ניהול כלים אינטראקטיבי

### הצעה לשיפור: שילוב ממשק ניהול כלים אינטראקטיבי

#### מה
הטמעת פאנל חדש בקונסולת RTL העברית, המאפשר למשתמשים לגשת ישירות לסט כלי אוטומציה מתקדמים מהארסנל. כל כלי יוצג ככרטיס אינטראקטיבי עם כפתור הפעלה, פרמטרים מותאמים אישית, ותיעוד מובנה.

#### למה
1. **הפחתת חיבור ל-API חיצוני**: עדכוני תצורה והפעלת כלים יתבצעו ישירות מהממשק, מה שמפחית את הצורך בשימוש בכלי שורת פקודה או בקריאות API ידניות.
2. **שיפור חווית המשתמש**: ממשק ויזואלי ידידותי יקל על צוות התפעול להפעיל כלים מורכבים בלי צורך בידע טכני עמוק.
3. **שימוש מוצדק בכלים**: יצירת מסגרת רשמית להפעלת כלים מהארסנל תמנע שימוש לא מבוקר ותוודא שהם מופעלים רק כאשר נדרשים.

#### איך
1. **עיצוב הממשק**:
   - יצירת תבנית כרטיסים לכל כלי בארסנל, כאשר כל כרטיס כולל:
     - שם הכלי ותיאור קצר.
     - פרמטרים הניתנים להגדרה על ידי המשתמש (כגון טווח תאריכים, סוגי נתונים).
     - כפתור "הפעלה" בולט.
     - קישור לתיעוד מלא של הכלי.
   - ארגון הכרטיסים בטאבים לפי קטגוריות (למשל: "ניטור", "אוטומציה", "ניתוח").

2. **הטמעה טכנית**:
   - פיתוח קומפוננטה חדשה ב-React/TypeScript להצגת הפאנל.
   - יצירת API פנימי חדש (`/api/arsenal/tools`) שמחזיר את רשימת הכלים הזמינים, פרמטריהם ותיעודם.
   - יצירת נקודת קצה להפעלת כלים (`/api/arsenal/run`) שמקבלת את פרטי ההפעלה ומעבירה אותם למנוע האוטומציה הרלוונטי.

3. **אבטחה והרשאות**:
   - שילוב מערכת הרשאות מבוססת-תפקידים כדי לקבוע מי רשאי להפעיל כל כלי.
   - רישום פעולות (logging) של כל הפעלות כלים למטרות ביקורת ומעקב.

4. **מעקב ומשוב**:
   - הצגת מצב הפעלה בזמן אמת ("מתבצע", "הסתיים", "נכשל").
   - אפשרות להציג תוצאות ודוחות מיידיים לאחר הפעלת הכלי.

#### הערך העסקי
הצעה זו מגבירה את האוטונומיה של המערכת על ידי מתן כלים חזקים למשתמשים הקצה, מפחיתה את התלות בצוות טכני למשימות חוזרות, ומגבירה את היעילות הכללית של הרשת.
