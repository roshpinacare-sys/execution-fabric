# שאלות-ותשובות: ניהול מחזור חיי משימות בלוח המשימות

> **קהל יעד**: מפעילי Dispatch, מנהלי Workers, וכל מי שמנהל משימות בקונסולת SAOS
> **מטרה**: לקצר זמן-לפתרון, למנוע חזרה על טעויות מוכרות, וליצור שפה משותפת

---

## 1. יצירת משימות

### ❌ טעות: כותרת משימה עמומה ("לתקן באג", "לשפר ביצועים")
**למה זה כואב**: Workers לא מבינים הקשר, Dispatch לא יכול לתעדף, מדדים לא ניתנים לאגרגציה

### ✅ תיקון: תבנית כותרת מובנית
```
[סוג] <פעולה ספציפית> ב־<רכיב/מודול> — <תוצאה מצופה>
```
**דוגמאות**:
- `[BUG] תיקון דליפת זיכרון ב־Worker Pool — יציבות 24h רצופות`
- `[FEAT] הוספת פילטור לפי סטטוס ב־API /tasks — קיצור זמן חיפוש ל־<100ms`
- `[OPS] ניקוי לוגים ישנים ב־Ledger — חיסכון 40% נפח דיסק`

### ✅ רשימת-בדיקה ליצירה (Definition of Ready)
- [ ] כותרת בתבנית לעיל
- [ ] תיאור: הקשר, שלבי שחזור, קריטריוני קבלה
- [ ] תוויות: `type:`, `priority:`, `component:`
- [ ] מוערך בנקודות/זמן (אפילו הערכה גסה)
- [ ] מוקצה או ב־Backlog גלוי

---

## 2. הקצאה ובעלות

### ❌ טעות: משימה "מוקצית לכולם" או ללא בעלים
**סימפטום**: סטטוס תקוע ב־`ASSIGNED` ימים, אף Worker לא מרים

### ✅ תיקון: בעלות יחידה + גיבוי מפורש
```yaml
assignee: "worker-7"
backup: "worker-3"  # אופציונלי, רק למשימות קריטיות
```
**כלל**: אם אין בעלים — המשימה חוזרת ל־`BACKLOG` אוטומטית אחרי 4h

### ❌ טעות: הקצאה לפי זמינות בלבד (מי פנוי עכשיו)
**תיקון**: הקצאה לפי **מומחיות + עומס נוכחי + רצף הקשר**
- Worker שטיפל ברכיב דומה השבוע → עדיפות
- Worker עם <3 משימות פעילות → עדיפות
- Worker שסיים משימה דומה ב־DONE לאחרונה → עדיפות

---

## 3. מעקב יומי (Standup-ready)

### ❌ טעות: עדכון סטטוס ללא הקשר ("עובד על זה", "כמעט גמור")
**תיקון**: עדכון במבנה קבוע — **מה נעשה / מה נתקע / מה צריך**
```markdown
## Task #1247 — [FEAT] פילטור /tasks
- **נעשה**: מודל נתונים + API endpoint + טסטים יחידה (85% כיסוי)
- **נתקע**: אינטגרציה עם Cache Layer — TTL לא מתרענן
- **צריך**: Code review מ־worker-3 (מומחה Cache), הערכת 30 דק'
```

### ❌ טעות: משימות "זומבי" — פתוחות >7 ימים בלי תנועה
**זיהוי אוטומטי**: שאילתה יומית → תג `stale` + התראה ל־Dispatch
**פעולה**: סגירה/פיצול/החזרה ל־Backlog תוך 24h

---

## 4. סגירה ואימות (Definition of Done)

### ❌ טעות: סימון `DONE` בלי אימות בפרודקשן
**תיקון**: שער סגירה חובה — **כל הקריטריונים מסומנים**
```markdown
## Definition of Done — חובה לכל משימה
- [ ] קוד ב־main + CI ירוק
- [ ] Deploy לסביבת Staging + Smoke test עובר
- [ ] Deploy לפרודקשן + בדיקת בריאות (health endpoint)
- [ ] תיעוד מעודכן (README / CHANGELOG / API docs)
- [ ] מטא-דאטה משימה מעודכן: זמן אמיתי, הערות סגירה
- [ ] אין התראות פעילות קשורות (Sentry, Logs, Metrics)
```

### ❌ טעות: סגירת משימה עם "נשאר ניקוי קטן" / "TODO בהמשך"
**תיקון**: פיצול — המשימה הנוכחית נסגרת **רק** כשהערך נמסר. השאר → משימה חדשה עם תווית `follow-up`

---

## 5. טעויות מערכתיות (Anti-patterns ארגוניים)

| Anti-pattern | סימפטום | תיקון מערכתי |
|---|---|---|
| **הצפת Backlog** | >200 משימות פתוחות, אין תעדוף ברור | WIP Limit גלובלי (למשל 50), ניקוי רבעוני אגרסיבי |
| **פינג-פונג הקצאות** | משימה עוברת 3+ Workers | הגבלת מעברים (מקס 2), תחקיר אחרי חריגה |
| **הערכות מנותקות** | הערכה 2h → ביצוע 2 ימים | כיול שבועי: השוואה הערכה vs מציאות, עדכון וולוסיטי |
| **ידע שבטי** | רק Worker X יודע איך לטפל ברכיב Y | תיעוד חובה ב־Wiki, Cross-training חודשי |

## 6. קיצורי מקלדת וזרימה מהירה (קונסולת RTL)

| פעולה | קיצור | הקשר |
|---|---|---|
| משימה חדשה | `Ctrl+N` | מכל מקום בלוח |
| חיפוש משימות | `Ctrl+K` | פוקוס מיידי על פילטור |
| מעבר למשימה הבאה/קודמת | `J` / `K` | במצב רשימה |
| פתיחת פרטים | `Enter` | על שורה נבחרת |
| שינוי סטטוס מהיר | `S` → מקליד אות ראשונה | `S` → `D` (Done), `S` → `B` (Blocked) |
| הקצאה לעצמי | `A` | על משימה נבחרת |
| הוספת הערה | `C` | Comment inline |

## 7. מטריקות בריאות לוח המשימות (ל־Dispatch)

```json
{
  "dashboard": "task-board-health",
  "widgets": [
    { "metric": "tasks_open_total", "threshold": { "warn": 100, "crit": 200 } },
    { "metric": "tasks_stale_7d", "threshold": { "warn": 5, "crit": 15 } },
    { "metric": "tasks_avg_cycle_time_hours", "threshold": { "warn": 48, "crit": 96 } },
    { "metric": "tasks_reassignment_rate", "threshold": { "warn": 0.15, "crit": 0.3 } },
    { "metric": "tasks_done_vs_created_7d", "threshold": { "warn": 0.8, "crit": 0.6 } }
  ]
}
```

**פעולה כשחוצים סף**:
- `warn` → דיון ב־Standup הבא
- `crit` → הפעלת נוהל חירום: הקפאת יצירת משימות חדשות, פוקוס על סגירה
