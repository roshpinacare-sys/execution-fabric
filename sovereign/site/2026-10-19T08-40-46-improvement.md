# הוספת כפתור 'חזרה לתחילת הרשימה' בלוח-המשימות למסכי מגע

# כפתור 'חזרה לתחילת הרשימה' בלוח-המשימות

## למה זה נדרש?
בלוח-המשימות (Dispatch → Workers), משתמשים במובייל ובמסכי מגע נאלצים לגלול ידנית לאורך רשימות ארוכות של משימות כדי לחזור לתחילת הרשימה לאחר ביצוע פעולה או בדיקה. זה יוצר חיכוך ומעכב את זרימת העבודה, במיוחד כאשר הרשימה ארוכה ודורשת גלילה מרובה.

## מה ההצעה?
להוסיף כפתור צף (Floating Action Button - FAB) בפינה הימנית-תחתונה של לוח-המשימות, שממוקם מעל תוכן הגלילה ונגיש תמיד. הלחיצה עליו מחליקה את הרשימה בחזרה לתחילה (למשימה הראשונה ברשימה) בצורה חלקה.

## איך זה עובד?
- הכפתור מוצג רק כאשר המשתמש גלול מטה יותר ממקום מסוים (למשל: אחרי 200px מהפס העליון).
- הוא מוסתר כאשר המשתמש בפס העליון של הרשימה כדי למנוע עומס חזותי.
- הלחיצה מפעילה אנימת גלילה חלקה (`scrollTo({ top: 0, behavior: 'smooth' })`) אל תחילת הרשימה.
- העיצוב מתאים ל-RTL: הכפתור ממוקם בפינה הימנית-תחתונה, עם מרחק מתאים מהקצה כדי לא לחפוף עם כפתורי מערכת.
- סמל הכפתור: חץ למעלה (`↑`) או אייקון סטנדרטי של חזרה להתחלה, עם ניגוד צבעים מתאים לקריאה.

## יתרונות
- מפחית משמעותית את מאמץ הגלילה במובייל.
- משפר את חוויית המשתמש במשימות תכופות של בדיקה וביצוע.
- תואם את עקרונות הנגישות והמובייל שבחוזק-הגלגל.
- קל ליישום ולא דורש שינוי במבנה הנתונים או בארכיטקטורה.

## דוגמה ליישום (פסקוד)
```javascript
// בדיקה אם להציג את הכפתור
window.addEventListener('scroll', () => {
  const btn = document.getElementById('scroll-to-top-btn');
  if (window.scrollY > 200) {
    btn.style.display = 'block';
  } else {
    btn.style.display = 'none';
  }
});

// פעולת הלחיצה
document.getElementById('scroll-to-top-btn').addEventListener('click', () => {
  window.scrollTo({
    top: 0,
    behavior: 'smooth'
  });
});
```

## הערות להטמעה
- יש לוודא שהכפתור לא חוסם אלמנטים קריטיים ב-RTL (למשל: תפריט או כפתורי פעולה ראשוניים).
- מומלץ להוסיף `aria-label="חזרה לתחילת הרשימה"` לנגישות.
- ניתן למקם את הכפתור בקומפוננטה קיימת של לוח-המשימות ללא צורך בשינוי מבנה עמודים.
