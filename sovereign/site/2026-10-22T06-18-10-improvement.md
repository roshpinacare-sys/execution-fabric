# מצב כהה אוטומטי עם ניגודיות מוגברת למסכים קטנים

## הצעה: מצב כהה אוטומטי עם ניגודיות מוגברת למובייל

### הבעיה
משתמשים בסביבות תאורה חלשה (לילה, חדרי שרתים, ניידות) חווים עייפות עיניים וסנוור מהרקע הבהיר הנוכחי. במובייל — שטח המסך קטן והבהירות המקסימלית לרוב נמוכה יותר — הבעיה מחריפה.

### הפתרון המוצע
1. **ערכת נושא כהה ייעודית** (`dark-mobile`) עם:
   - רקע `#0B0D12` (כמעט שחור, חוסך סוללה ב-OLED)
   - טקסט ראשי `#E8EAF0` (יחס ניגודיות 14.2:1)
   - טקסט משני `#9AA3AD` (יחס 7.1:1 — עומד ב-WCAG AAA לטקסט גדול)
   - גבולות/מפרידים `#23272F`
   - הדגשות/קישורים `#58A6FF` (כחול בהיר, ניגודיות 6.8:1 על הרקע)
   - מצבי שגיאה/אזהרה: `#F85149` / `#D29922` (נבדקו ניגודיות)

2. **הפעלה אוטומטית** דרך `prefers-color-scheme: dark` + זיהוי רוחב מסך `< 768px` — נטען כברירת-מחדל במובייל, אופציונלי בדסקטופ.

3. **מתג ידני נגיש** בפינה עליונה (aria-label="החלף ערכת נושא") — נשמר ב-localStorage, גובר על האוטומטי.

4. **CSS Custom Properties** בלבד — ללא JS runtime להחלפה, מעבר חלק עם `transition: background-color 0.2s, color 0.2s`.

### יישום טכני
```css
:root {
  --bg-primary: #FFFFFF;
  --text-primary: #1A1D23;
  --text-secondary: #4A5058;
  --border-color: #E1E4E8;
  --accent: #0969DA;
}

@media (prefers-color-scheme: dark) and (max-width: 767px) {
  :root:not([data-theme="light"]) {
    --bg-primary: #0B0D12;
    --text-primary: #E8EAF0;
    --text-secondary: #9AA3AD;
    --border-color: #23272F;
    --accent: #58A6FF;
  }
}

[data-theme="dark"] {
  --bg-primary: #0B0D12;
  --text-primary: #E8EAF0;
  --text-secondary: #9AA3AD;
  --border-color: #23272F;
  --accent: #58A6FF;
}
```

### מדדי קבלה
- ✅ יחס ניגודיות ≥ 7:1 לכל טקסט גוף במובייל כהה
- ✅ מעבר אוטומטי ללא הבהוב (FOUC) — משתנים מוגדרים ב-`:root` לפני טעינת תוכן
- ✅ מתג ידני נגיש מקלדת (Tab + Enter/Space) עם `role="switch"` ו-`aria-checked`
- ✅ שמירת העדפה חוצה-סשנים
- ✅ אפס שינויים ב-HTML/JS קיים — רק הוספת CSS ורכיב מתג בודד

### ערך מוסף
- נגישות אמיתית (WCAG 2.1 AA/AAA) לאוכלוסייה רחבה
- חיסכון סוללה במכשירי OLED (עד 30% פחות צריכת מסך)
- חוויה מקצועית תואמת-ציפיות במובייל 2024+
- בסיס עתידי לערכות נושא נוספות (high-contrast, sepia, custom)
