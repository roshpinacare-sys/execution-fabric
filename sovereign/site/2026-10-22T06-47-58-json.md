# לוח-מחוונים בריאות מערכתית — תצורת JSON

מבנה נתונים יחיד שהקונסולה יכולה לצרוך ישירות כדי להציג תמונת-מצב מלאה של בריאות המוצר בזמן אמת.

## שדות עיקריים

| שדה | סוג | תיאור |
|------|------|----------|
| `timestamp` | ISO 8601 | מועד דגימה אחרון |
| `availability` | object | מדדי זמינות (uptime, error rate, latency p95) |
| `closureRate` | object | קצב סגירת משימות (done/failed/pending, trend 7d) |
| `learningQuality` | object | איכות למידה (high-findings open/resolved, false-positive rate) |
| `chainHealth` | object | בריאות שרשרת (blocks, failed, fork-depth, sync-lag) |
| `alerts` | array | התראות פעילות (severity, component, message) |

## שימוש בקונסולה
- הקונסולה שולפת `/api/health/dashboard` (GET) ומקבלת את המבנה לעיל.
- תצוגה: 4 כרטיסים ראשיים + רשימת התראות נגללת.
- רענון אוטומטי כל 30 שניות; כפתור רענון ידני.
- צבעוניות: ירוק (תקין), צהוב (watch), אדום (attention) לפי שדות `alerts`.

## הרחבות עתידיות
- הוספת `resourceUsage` (CPU, RAM, disk, network).
- פילוח לפי סביבה (prod/staging/dev).
- ייצוא CSV/PDF לדוחות שבועיים.
