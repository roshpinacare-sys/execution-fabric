# מצב כהה אוטומטי עם מתג ידני נגיש

# הצעה: מצב כהה אוטומטי עם מתג ידני נגיש

## הבעיה
קונסולת ה-RTL הנוכחית פועלת רק במצב בהיר. משתמשים שעובדים בלילה, בסביבות חשוכות, או עם רגישות לאור חזק — חווים עייפות עיניים מיותרת. אין דרך להחליף ערכת צבעים בלי לערוך CSS ידנית.

## הפתרון המוצע
1. **זיהוי אוטומטי** — קריאת `prefers-color-scheme` בעת טעינה והחלה מיידית.
2. **מתג ידני נגיש** — כפתור בפינה העליונה (ימין ב-RTL) עם:
   - תווית ARIA ברורה: `aria-label="החלף מצב כהה/בהיר"`
   - מיקוד מקלדת נראה (`:focus-visible`)
   - גודל יעד מגע ≥ 44×44px
   - אייקון שמש/ירח SVG מוטמע (ללא בקשות רשת)
3. **שמירת העדפה** — `localStorage.setItem('theme', 'dark'|'light'|'auto')` עם עדיפות: ידני > שמור > מערכת.
4. **משתני CSS מאוחדים** — כל הצבעים, צללים, גבולות וטקסטים מוגדרים כ-custom properties תחת `:root` ו-`[data-theme="dark"]`, כך שהחלפה מיידית וללא הבהוב (FOUC).
5. **כיבוד `prefers-reduced-motion`** — מעבר צבעים מיידי ללא אנימציה כשהמשתמש מבקש הפחתת תנועה.

## קבצים שיושפעו
- `styles/variables.css` — הגדרת כל הטוקנים (צבעי רקע, טקסט, גבול, צל, קישור, קוד, התראות, כפתורים, טפסים).
- `styles/theme.css` — כללי `[data-theme="dark"]` ומדיה קוורי `@media (prefers-color-scheme: dark)`.
- `scripts/theme-toggle.js` — מודול ES קטן (≤ 2KB gzipped) המטפל בזיהוי, מתג, שמיעה ושחזור.
- `index.html` — הוספת `<script type="module" src="/scripts/theme-toggle.js"></script>` וכפתור המתג ב-header.

## קריטריוני קבלה (Definition of Done)
- [ ] טעינה ראשונה במצב כהה כשהמערכת על Dark Mode — ללא הבהוב לבן.
- [ ] לחיצה על המתג מחליפה מיידית ומעדכנת `localStorage`.
- [ ] רענון דף שומר את הבחירה הידנית.
- [ ] שינוי הגדרת מערכת (OS) משנה ערכה רק כשהמשתמש לא בחר ידנית (`auto`).
- [ ] ניווט מקלדת: `Tab` מגיע למתג, `Enter`/`Space` מפעיל, פוקוס נראה בבירור.
- [ ] קורא מסך מכריז "מצב כהה מופעל" / "מצב בהיר מופעל" בעת שינוי.
- [ ] כל הרכיבים הקיימים (כרטיסים, טבלאות, מודלים, טוסטים, סרגל צד) נראים תקין בשני המצבים — ללא טקסט בלתי קריא או גבולות נעלמים.
- [ ] גודל חבילת JS הנוספת ≤ 2KB gzipped.

## הערכת מאמץ
- **CSS**: ~120 שורות משתנים + 60 שורות כללי כהה = ~180 שורות.
- **JS**: ~80 שורות מודול ES יחיד.
- **HTML**: 2 שורות (כפתור + סקריפט).
- **בדיקות ידניות**: 15 דקות ב-Chrome/Firefox/Safari + כלי נגישות (axe, ניווט מקלדת, VoiceOver/TalkBack).

## ערך מיידי
- נגישות משופרת (WCAG 2.1 AA — ניגודיות, מנגנון החלפה).
- חוויית מובייל/לילה טובה משמעותית.
- תשתית מוכנה לערכות נוספות בעתיד (למשל `high-contrast`, `sepia`).
