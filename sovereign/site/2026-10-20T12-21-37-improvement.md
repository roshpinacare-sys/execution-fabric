# מדדי ביצועי עובדים וזיהוי צווארי בקבוק

## מדדי ביצועי עובדים — הגדרה ותצוגה

קובץ זה מגדיר את קבוצת המדדים המרכזית לניטור ביצועי ה-Workers ברשת. המדדים מאפשרים זיהוי מהיר של עובדים איטיים, סוגי משימות בעייתיים, וצווארי בקבוק מערכתיים.

### מטריקות ליבה

| מדד | תיאור | סף התראה | יחידה |
|------|---------|-----------|--------|
| `task_duration_p50` | זמן חציוני להשלמת משימה | > 30 שניות | ms |
| `task_duration_p95` | אחוזון 95 של זמן ביצוע | > 120 שניות | ms |
| `failure_rate` | שיעור כישלונות מסך המשימות | > 5% | % |
| `retry_rate` | שיעור ניסיונות חוזרים | > 10% | % |
| `throughput_per_min` | משימות מושלמות לדקה | < 1 | tasks/min |
| `queue_lag` | פיגור תור הממתינות | > 50 משימות | count |

### פילוח נדרש

כל מדד מחושב בנפרד עבור:
- **סוג עובד** (worker_type): `code-review`, `test-runner`, `build`, `deploy`, `analysis`
- **קטגוריית משימה** (task_category): `critical`, `standard`, `background`
- **חלון זמן** (time_window): `5m`, `15m`, `1h`, `24h`

### לוגיקת זיהוי חריגות

```
IF failure_rate > 5% AND task_count > 20
  → TAG: "degraded_performance"

IF p95_duration > 3 * p50_duration
  → TAG: "high_variance" (פיזור זמנים חריג)

IF queue_lag GROWING for 3 consecutive windows
  → TAG: "backlog_building"

IF throughput DROPS > 50% vs 1h baseline
  → TAG: "capacity_loss"
```

### שימוש אופרטיבי

- **משמרת לילה**: סריקה מהירה של שורות עם TAGs לא-ריקים
- **תחקור**: לחיצה על סוג עובד → פירוט 10 המשימות האיטיות ביותר
- **אסקלציה**: אם >2 סוגי עובדים ב-degraded_performance בו-זמנית → התראת מערכת
