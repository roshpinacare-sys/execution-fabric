# לוח-מחוונים בריאות מערכתית — מדדי זמינות, ביצועים ומשמרת לילה

אובייקט JSON זה מיועד להצגה בקונסולה RTL ומשמש כמקור אמת יחיד (Single Source of Truth) לכל מדדי הבריאות התפעוליים של המוצר. הוא מרכז ארבעה תחומים עיקריים:

1. **זמינות רכיבים (Availability)** — סטטוס חי/מת, uptime באחוזים, זמן מאז כשל אחרון.
2. **ביצועים (Performance)** — אחוזונים של זמני תגובה (p50, p95, p99), throughput בבקשות/שנייה.
3. **אמינות (Reliability)** — שיעור שגיאות (error rate), ספירת כשלים רצופים, מצב circuit-breaker.
4. **משמרת לילה (Night Watch)** — האם פעילה, משך הפעלה נוכחי, משימות שנבדקו, חריגות שנמצאו.
5. **שרשרת-אמת (Ledger Health)** — גובה בלוק אחרון, קצב בלוקים/דקה, כשלים רצופים, מצב סנכרון.

כל השדות הם מספריים או בוליאניים — אין מחרוזות חופשיות — כדי לאפשר עיבוד אוטומטי, התראות מבוססות-סף וגרפים בזמן אמת.

## דוגמת מבנה (להמחשה בלבד — ה-payload למטה הוא הנתון החי)

```json
  "responseTimeMs": { "p50": 42, "p95": 118, "p99": 287 },

}
```

## הנחיות תצוגה בקונסולה
- **צבעים**: ירוק ≤ 1% שגיאות / p95 ≤ 200ms / uptime ≥ 99.9% — אדום אחרת.
- **רענון**: כל 10 שניות דרך `/api/metrics/health-dashboard`.
- **התראות**: כששדה כלשהו חורג מסף מוגדר (ראו `thresholds` ב-payload), הקונסולה מציגה הבהוב אדום וכותרת "⚠ חריגה".
- **RTL**: כל התוויות בעברית, יישור לימין, גופן מונוספייס לערכים מספריים.

## שימוש אופרטיבי
- **מפעיל אנושי**: מבט מהיר — הכל ירוק? המשך. אדום? פתח פירוט.
- **אוטומציה**: סקריפט ניטור חיצוני קורא את ה-endpoint, בודק `thresholds`, שולח התראה ל-Slack/PagerDuty.
- **היסטוריה**: הערכים נשמרים ב-Ledger כל דקה — מאפשר גרפים רטרוספקטיביים.
