## שאלות מרכזיות

### 1. איך מיישמים פונקציית חישוב ממוצע נעים (Moving Average) ברשת?
**תשובה:**
פונקציית הממוצע הנע חיונית לניתוח טרנדים בנתוני זרימה. הנה דוגמת קוד מימוש:
```javascript
function calculateMovingAverage(data, windowSize) {
  const result = [];
  for (let i = 0; i < data.length; i++) {
    if (i < windowSize - 1) {
      result.push(null);
      continue;
    }
    
    let sum = 0;
    for (let j = i - windowSize + 1; j <= i; j++) {
      sum += data[j];
    }
    result.push(sum / windowSize);
  }
  return result;
}
```
**הסבר:** הפונקציה לוקחת מערך נתונים וגודל חלון, ומחזירה מערך עם הממוצע הנע. היא מתחילה להחזיר ערכים רק לאחר שיש מספיק נתונים בחלון.

### 2. איך מטפלים במקרים של Deadlock בסביבת ריבוי תהליכים?
**תשובה:**
Deadlock מתרחש כאשר שני תהליכים או יותר ממתינים זה לזה למשאבים שהאחר חוסם. להלן אסטרטגיות למניעה:

1. **נעילה סדרתית (Lock Ordering):**
   - הגדר סדר קבוע לבקשת נעילות
   - יישם את אותו סדר בכל התהליכים

2. **זמן המתנה עם Timeout:**
   ```javascript
   const lock = await mutex.acquire();
   try {
     await Promise.race([
       doCriticalTask(),
       new Promise((_, reject) => setTimeout(() => reject(new Error('Timeout')), 5000))
     ]);
   } finally {
     mutex.release(lock);
   }
   ```

3. **שימוש באלגוריתם הבנקאי (Banker's Algorithm):**
   - בדוק מראש אם הקצאת המשאבים בטוחה
   - יישם מפת מצבים למניעת מצבים לא בטוחים

### 3. איך מייעלים ביצועים של שאילתות על מסדי נתונים גדולים?
**תשובה:**
אופטימיזציה של שאילתות מסד נתונים גדול כוללת מספר שלבים:

1. **אינדקסים ואינדקסים מרוכבים:**
   ```sql
   CREATE INDEX idx_user_status ON users(status) WHERE status = 'active';
   CREATE INDEX idx_order_date_user ON orders(order_date, user_id);
   ```

2. **חלוקת נתונים (Sharding):**
   ```javascript
   // דוגמת חלוקת נתונים לפי טווח מזהה משתמש
   function getShard(userId) {
     const shardCount = 4;
     return userId % shardCount;
   }
   ```

3. **שימוש ב-Cache מסד נתונים:**
   - הפעלת Query Caching
   - שימוש ב-Redis למטמון תוצאות נפוצות

4. **סריאליזציה נכונה:**
   ```javascript
   // במקום:
   db.collection.find().toArray();
   
   // השתמש בסריאליזציה:
   db.collection.find().project({ _id: 0, name: 1, email: 1 });
   ```

### 4. איך מיישמים בקרת גרסאות (Version Control) למשאבים סטטיים?
**תשובה:**
בקרת גרסאות למשאבים סטטיים חיונית למניעת באגי cache:

1. **שימוש ב-Hash של קובץ:**
   ```javascript
   const crypto = require('crypto');
   const fs = require('fs');
   
   function getFileHash(filePath) {
     const fileData = fs.readFileSync(filePath);
     return crypto.createHash('sha256').update(fileData).digest('hex');
   }
   ```

2. **שילוב עם Build Pipeline:**
   ```yaml
   # דוגמת GitHub Action
   - name: Generate version hash
     run: |
       VERSION=$(git rev-parse --short HEAD)
       echo "version=$VERSION" >> $GITHUB_ENV
   
   - name: Build with version
     run: |
       npm run build -- --env.version=${{ env.version }}
   ```

3. **Cache Busting ב-HTML:**
   ```html
   <link rel="stylesheet" href="/styles/main.css?v={{version}}">
   <script src="/scripts/bundle.js?v={{version}}"></script>
   ```
