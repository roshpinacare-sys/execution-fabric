# פאנל בריאות מערכת

## סקירה כללית

פאנל בריאות מערכת הוא מרכז פיקוח ויזואלי המציג את מצב הבריאות והביצועים של רשת-הביצוע בזמן-אמת. הממשק מאפשר למשתמשים לעקוב אחר מפתחי בריאות קריטיים, לזהות מגמות חריגות ולקבל התראות מוקדמות על סיכונים פוטנציאליים.

## קטגוריות נתונים

### 1. ביצועי רשת
- **משימות פעילות**: מספר המשימות הפעילות כעת
- **שיעור הצלחה**: אחוז משימות שהצליחו מאז הפעלה אחרונה
- **זמן ממוצע לביצוע**: זמן ממוצע להשלמת משימה (בשניות)
- **תזמון תהליכים**: הצגת תזמון הפעלת תהליכים עתידיים

### 2. בריאות שרשרת האמת
- **אורך שרשרת**: מספר הבלוקים בשרשרת האמת הפעילה
- **קצב גידול**: מספר הבלוקים המתווספים בדקה
- **אימות כוח**: אחוז הבלוקים שאומתו בצלחת האחרונה
- **זמן סנכרון**: זמן ממוצע לסנכרון בין צמתים

### 3. זיכרון ומשאבים
- **זיכרון בשימוש**: כמות זיכרון נוכחית (במגה-בייט)
- **שימוש במעבד**: אחוש המעבד הנוכחי
- **לולאות פתוחות**: מספר הלולאות שלא נסגרו
- **נתונים שנלמדו**: כמות הנתונים שנלמדו (במגה-בייט)

### 4. פעילות הארסנל
- **כלים זמינים**: מספר הכלים בארסנל
- **שימוש פעיל**: כלים בשימוש פעיל כעת
- **ביצועים ממוצעים**: זמן ביצוע ממוצע של כלי
- **שגיאות**: מספר שגיאות בהפעלת כלים

### 5. מצב משמרת הלילה
- **צמתים פעילים**: מספר הצמתים במשמרת הלילה
- **משימות מתוזמנות**: מספר המשימות המתוזמנות למשמרת
- **זמן תגובה ממוצע**: זמן תגובה ממוצע לאירועים
- **אירועים קריטיים**: מספר האירועים שדורשים תשומת לב

## ממשק משתמש

### תצוגה כללית
- **לוח מחוונים**: תצוגה ויזואלית של כל המדדים העיקריים
- **גרף מגמות**: גרף זמן המציג את ההתפתחות של מדדים מרכזיים
- **מפת חום**: תצוגת מפת חום של צמתים ומצבם

### תצוגת פירוט
- **מסננים**: סינון לפי סוג מדד, טווח זמן, חשיבות
- **היסטוריה**: תצוגת היסטוריה של מדדים
- **התראות**: התראות מותאמות אישית למדדים קריטיים

### פעולות
- **רענון ידני**: עדכון ידני של הנתונים
- **ייצוא דוח**: ייצוא נתונים ל-CSV או JSON
- **התראות**: הגדרת התראות עבור מדדים ספציפיים

## יישום

### שלב 1: יצירת API
- פיתוח API חדש (`/api/health`) שמחזיר את כל נתוני הבריאות
- תזמון איסוף נתונים קבוע (כל 30 שניות)
- אימוץ פורמט JSON סטנדרטי לנתונים

### שלב 2: פיתוח ממשק
- בניית קומפוננטות React להצגת נתונים
- שימוש בספריות ויזואליזציה (D3.js, Chart.js)
- יישום עיצוב רספונסיבי

### שלב 3: אינטגרציה
- חיבור ה-API לממשק הקיים
- הוספת כרטיסיית "בריאות מערכת" לתפריט הראשי
- ייבוץ עם מערכת ההתראות הקיימת

### שלב 4: בדיקות
- בדיקות יחידה ל-API
- בדיקות אינטגרציה של הממשק
- בדיקות עומס לוודא ביצועים תחת עומס גבוה
