# ממשק מגע מותאם ללוח המשימות עם מחוות גרירה ושחרור

# הצעה: ממשק מגע מותאם ללוח המשימות

## הבעיה
לוח המשימות (Dispatch → Workers) תוכנן בעיקר לעכבר ומקלדת. במסכי מגע:
- גרירת כרטיסים בין עמודות לא עובדת או מקרטעת
- אין משוב ויזואלי כשמתחילים גרירה
- תפריטי פעולות (הקצאה, עדיפות, העברה) נגישים רק בקליק ימני
- כפתורים קטנים מדי לאצבע (פחות מ-44×44px)
- גלילה אופקית של העמודות נתקעת בגרירה

## הפתרון המוצע
### 1. גרירה ושחרור מותאמת מגע
```css
/* אזורי גרירה מוגדלים */
.task-card {
  touch-action: none; /* מונע גלילה בזמן גרירה */
  min-height: 48px;
}

.task-card.dragging {
  opacity: 0.6;
  transform: scale(1.02);
  box-shadow: 0 8px 24px rgba(0,0,0,0.15);
  z-index: 1000;
}

.drop-zone.active {
  background: var(--color-primary-light);
  border: 2px dashed var(--color-primary);
}
```

### 2. הקשה ארוכה (Long Press) לתפריט פעולות
- 500ms הקשה → נפתח תפריט רדיאלי/תחתון עם: הקצה, שנה עדיפות, העבר עמודה, שכפל, ארכב
- תפריט נסגר בלחיצה מחוץ לו או בחירת פעולה
- נגיש גם במקלדת: Shift+F10 או Menu key

### 3. אינדיקטורים ויזואליים ברורים
- **מצב המתנה**: כרטיס מקבל גבול כתום דק
- **מצב גרירה פעילה**: כרטיס מורם עם צל, עמודות יעד מודגשות
- **מצב שחרור תקין**: אנימציית "נפילה" למקום
- **מצב ביטול**: החלקה חזרה למקום המקורי

### 4. אזורי מגע מינימליים
| רכיב | גודל נוכחי | גודל מוצע |
|-------|-------------|------------|
| כפתור פעולה בכרטיס | 28×28px | 44×44px |
| ידית גרירה | לא קיים | 44×44px (צד ימין) |
| כותרת עמודה | 32px גובה | 48px גובה |
| תג עדיפות | 20×20px | 32×32px |

### 5. ניווט מקלדת משופר (תומך גם במגע)
- `Tab` / `Shift+Tab` — ניווט בין כרטיסים
- `Enter` / `Space` — בחירת כרטיס
- `Arrow keys` — מעבר בין עמודות
- `Ctrl+Arrow` — הזזת כרטיס בין עמודות
- `Escape` — ביטול גרירה/סגירת תפריט

## קבצים לעדכון
- `src/components/TaskBoard/TaskCard.tsx` — הוספת `onTouchStart`, `onTouchMove`, `onTouchEnd`
- `src/components/TaskBoard/Column.tsx` — drop zones עם `onDragOver`, `onDrop`
- `src/hooks/useTouchDrag.ts` — הוק חדש ללוגיקת מגע
- `src/styles/task-board-touch.css` — סגנונות ייעודיים

## מדדי הצלחה
- ✅ גרירת כרטיס בין עמודות עובדת חלק ב-iOS Safari, Chrome Android
- ✅ 100% מהפעולות נגישות במגע ללא תפריט הקשר
- ✅ ציון Lighthouse Accessibility ≥ 95
- ✅ גודל יעד מגע מינימלי 44×44px בכל הרכיבים האינטראקטיביים
