# מדריך לפיתוח ריבונות חדשה

## הקדמה
מדריך זה מספק מדריך מעשי למפתחים וריבונים חדשים המעוניינים להקים ריבונות חדשה ברשת. המדריך מכסה את כל השלבים מהגדרת התשתית הראשונית ועד לפריסה סופית והצטרפות לשרשרת האמת.

## 1. הכנת הסביבה

### דרישות מערכת
- Node.js (v18.0.0 ומעלה)
- Docker (גרסה 20.10 ומעלה)
- Git
- גישה למאגר הקוד הראשי של הרשת

### התקנה מקומית
```bash
# שכפול המאגר הראשי
git clone https://github.com/saos-dex/fabric.git
cd fabric

# התקנת תלויויות
npm install

# בניית הפרויקט
npm run build
```

## 2. יצירת ריבונות חדשה

### יצירת פרויקט חדש
השתמש בפקודה הבאה כדי ליצור תבנית לריבונות חדשה:

```bash
npm run create-sovereignty -- --name "ריבונות-הדגמה"
```

זה ייצור תיקייה חדשה עם:
- תיקיית `src` עם קבצי המקור
- קובץ `package.json` מותאם
- קובץ `.env.example` עם משתני סביבה נדרשים
- קובץ `README.md` בסיסי

### מבנה פרויקט טיפוסי
```
ריבונות-הדגמה/
├── src/
│   ├── handlers/          # ממשקי API
│   ├── services/          # שירועים עסקיים
│   ├── utils/             # כלי עזר
│   └── index.js          # נקודת כניסה ראשית
├── tests/                 # בדיקות
├── config/                # קבצי תצורה
├── package.json
└── .env.example
```

## 3. פיתוח הלוגיקה העסקית

### יצירת שירוע ראשון
```javascript
// src/services/demoService.js

class DemoService {
  constructor() {
    this.data = [];
  }

  async addItem(item) {
    // הוספת לוגיקת אימות
    if (!item || !item.name) {
      throw new Error('פריט לא תקין');
    }
    
    // הוספת הפריט
    this.data.push({
      id: Date.now(),
      ...item,
      createdAt: new Date().toISOString()
    });
    
    return this.data[this.data.length - 1];
  }

  async getItems() {
    return this.data;
  }
}

module.exports = new DemoService();
```

### יצירת ממשק API
```javascript
// src/handlers/demoHandler.js
const demoService = require('../services/demoService');

module.exports = {
  async addItem(req, res) {
    try {
      const item = await demoService.addItem(req.body);
      res.status(201).json(item);
    } catch (error) {
      res.status(400).json({ error: error.message });
    }
  },

  async getItems(req, res) {
    try {
      const items = await demoService.getItems();
      res.json(items);
    } catch (error) {
      res.status(500).json({ error: error.message });
    }
  }
};
```

## 4. כתיבת בדיקות

### דוגמה לבדיקה יחידה
```javascript
// tests/demoService.test.js
const DemoService = require('../src/services/demoService');

describe('DemoService', () => {
  let demoService;

  beforeEach(() => {
    demoService = new DemoService();
  });

  test('should add item successfully', async () => {
    const item = { name: 'פריט הדגמה', value: 100 };
    const result = await demoService.addItem(item);
    
    expect(result).toMatchObject({
      ...item,
      id: expect.any(Number),
      createdAt: expect.any(String)
    });
    expect(demoService.data).toHaveLength(1);
  });

  test('should throw error for invalid item', async () => {
    await expect(demoService.addItem({})).rejects.toThrow('פריט לא תקין');
  });
});
```

## 5. תצורה ופריסה

### קובץ .env
```bash
# העתק את הקובץ ל-.env ועדכן את הערכים
cp .env.example .env
```

ערוך את קובץ `.env` עם הפרטים הנדרשים:
```
PORT=3000
NODE_ENV=development
DATABASE_URL=postgresql://user:password@localhost:5432/sovereign_demo
JWT_SECRET=your-secret-key
```

### פריסה עם Docker
```bash
# בניית התמונה
docker build -t sovereign-demo .

הרצת המיכל
docker run -p 3000:3000 sovereign-demo
```

4. המתן לאישור מריבונות קיימות

### פריסה סופית
