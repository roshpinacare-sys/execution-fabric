# סרגל ניווט צדדי מתקפל עם קיצורי מקלדת ללוח המשימות

# הצעה: סרגל ניווט צדדי מתקפל עם קיצורי מקלדת

## הבעיה
בלוח המשימות (Dispatch → Workers) המשתמשים נאלצים להשתמש בעכבר כדי לעבור בין תצוגות שונות, מסננים ותורים. זה מאט את זרימת העבודה, במיוחד למפעילים שמנהלים עשרות משימות במקביל.

## הפתרון המוצע
סרגל ניווט צדדי (Sidebar) קבוע-למחצה עם:

### מבנה הסרגל
- **אזור תצוגות**: מעבר בין "כל המשימות", "התור שלי", "ממתינות לאישור", "נכשלו"
- **אזור מסננים**: סטטוס, עדיפות, מוקצה, טווח תאריכים
- **אזור פעולות מהירות**: יצירת משימה חדשה, רענון, ייצוא
- **מצב מכווץ/מורחב**: אייקונים בלבד / אייקונים + טקסט

### קיצורי מקלדת
| קיצור | פעולה |
|--------|--------|
| `Ctrl/Cmd + Shift + N` | משימה חדשה |
| `Ctrl/Cmd + 1-4` | מעבר לתצוגה 1-4 |
| `Ctrl/Cmd + F` | פוקוס לחיפוש/סינון |
| `Ctrl/Cmd + B` | כיווץ/הרחבת הסרגל |
| `Esc` | סגירת פאנלים פתוחים |
| `Tab` / `Shift+Tab` | ניווט בין אזורי הסרגל |
| `Enter` / `Space` | הפעלת פריט נבחר |
| חיצים ↑↓ | ניווט בתוך רשימה |

### נגישות
- `role="navigation"` עם `aria-label="ניווט ראשי ללוח משימות"`
- כל פריט: `role="menuitem"` עם `tabindex=-1` (roving tabindex)
- פוקוס ויזואלי ברור (outline 2px solid var(--focus-color))
- תמיכה ב-`prefers-reduced-motion` לאנימציות
- מצב מכווץ שומר `aria-expanded="false"` עם tooltips

### התנהגות רספונסיבית
- **Desktop (≥1024px)**: סרגל קבוע בצד ימין (RTL), רוחב 280px מורחב / 64px מכווץ
- **Tablet (768-1023px)**: סרגל נשלף (off-canvas) עם overlay
- **Mobile (<768px)**: מגירה תחתונה (bottom sheet) עם אזורי גלילה נפרדים

## יישום טכני
```tsx
// components/TaskBoardSidebar.tsx
const Sidebar = ({ collapsed, onToggle }) => (
  <nav
    role="navigation"
    aria-label="ניווט ראשי ללוח משימות"
    className={cn(
      'fixed right-0 top-0 h-full bg-surface border-l border-border',
      'transition-width duration-200 ease-out',
      collapsed ? 'w-16' : 'w-72'
    )}
  >
    <SidebarTrigger onClick={onToggle} aria-expanded={!collapsed} />
    <SidebarContent collapsed={collapsed} />
  </nav>
);
```

CSS מינימלי למעברים חלקים:
```css
.sidebar {
  transition: width 200ms cubic-bezier(0.4, 0, 0.2, 1);
}
.sidebar.collapsed .label { display: none; }
.sidebar.collapsed .icon { margin: 0 auto; }
@media (prefers-reduced-motion: reduce) {
  .sidebar { transition: none; }
}
```

## מדדי הצלחה
- זמן ממוצע למעבר בין תצוגות: < 1.5 שניות (מול ~4 שניות היום)
- שימוש בקיצורי מקלדת: > 40% מהמעברים תוך 30 יום
- ציון נגישות (axe): 0 violations ברמת AA
- שביעות רצון מפעילים (סקר פנימי): ≥ 4.2/5

## תלות וסיכונים
- **תלות**: ספריית קיצורי מקלדת (למשל `hotkeys-js` או מימוש עצמי קל)
- **סיכון נמוך**: רכיב UI עצמאי, לא נוגע בלוגיקת נתונים
- **בדיקות**: יחידה (קיצורים), אינטגרציה (ניווט), E2E (זרימות מפעיל)
