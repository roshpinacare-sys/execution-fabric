# הפיכת כרטיס 'מדדי רשת' לאינטראקטיבי: סינון, מיון ופרטי בלוק בלחיצה

# הצעה: כרטיס 'מדדי רשת' אינטראקטיבי

## המצב הנוכחי
- הקונסולה מציגה את `/api/metrics` כטבלה סטטית (בלוקים, כשלים, קצב, בריאות).
- אין אפשרות לסנן לפי טווח זמן, סטטוס או סוג בלוק.
- לחיצה על שורה לא פותחת פרטי בלוק (hash, timestamp, payload size, validator).
- מיון עמודות לא קיים — המשתמש רואה סדר הגעה בלבד.

## השיפור המוצע
### 1. סרגל כלים מעל הטבלה
- **סינון טווח זמן**: בחירת `last 1h / 6h / 24h / 7d / custom` — שולח פרמטר `?since=` ל-API הקיים (תואם לאחור).
- **סינון סטטוס**: צ'קבוקסים `✅ בוצע / ❌ כשל / ⏳ ממתין` — פרמטר `?status=`.
- **חיפוש טקסט חופשי**: על hash, validator, תגית — `?q=`.
- כפתור **איפוס** מחזיר ברירת מחדל.

### 2. מיון עמודות
- כותרות עמודות הופכות לכפתורי מיון (▲/▼).
- מיון צד-לקוח ראשוני (ללא בקשת רשת נוספת) — מהיר לטבלאות עד 500 שורות.
- אינדיקטור עמודת מיון פעילה נשמר ב-`localStorage` לביקורים חוזרים.

### 3. מודל פרטי בלוק (דריל-דאון)
- לחיצה על שורה פותחת מודל צדדי (slide-over) עם:
  - **Hash מלא** + כפתור העתקה.
  - **Timestamp** בפורמט מקומי + UTC.
  - **Payload size** (bytes) + סוג תוכן.
  - **Validator ID** + קישור לכרטיס הצי (`/arsenal/:id`).
  - **קישור ל-Ledger Explorer** (אם קיים) — `?block=<hash>`.
- סגירה ב-ESC, קליק מחוץ, או כפתור סגירה.

### 4. מצבי טעינה ושגיאה
- Skeleton rows בזמן fetch.
- Toast שגיאה לא פולשני עם כפתור "נסה שוב".
- מצב ריק: איור + הודעה "אין בלוקים בטווח הנבחר".

## למה זה ערך גבוה
- **מדיד**: זמן לאיתור בלוק בעייתי יורד מ-דקות לשניות.
- **בר-שימוש מיידי**: עובד על API קיים, אין שינוי בקונטרקט.
- **UX קונקרטי**: הופך כרטיס פסיבי לכלי חקירה יומיומי למפעילים.
- **סיכון נמוך**: רכיב צד-לקוח בלבד, ניתן להסרה ב-feature flag.

## תוכנית מימוש (קווים מנחים)
1. **רכיב חדש**: `NetworkMetricsCard.tsx` מחליף את הטבלה הנוכחית.
2. **Hooks**: `useMetrics(filters, sort)` — מטפל ב-fetch, cache, debounce (300ms).
3. **State**: `filters`, `sortConfig`, `selectedBlock` ב-`useReducer` מקומי.
4. **סגנון**: Tailwind + Headless UI ל-modal נגיש (ARIA).
5. **בדיקות**: Storybook stories לכל מצב + Cypress e2e לסינון/מיון/דריל-דאון.
6. **Feature flag**: `NEXT_PUBLIC_INTERACTIVE_METRICS=true` לפריסה הדרגתית.
