# מדדי ביצועי API — זמני תגובה, שגיאות ותפוקה לפי נקודת קצה

# מדדי ביצועי API — תצורת JSON לקונסולה

אובייקט זה מספק תמונת מצב מלאה של ביצועי כל נקודות הקצה במערכת. מיועד להזנה ישירה לרכיב תצוגת מדדים בקונסולת הניהול.

## מבנה הנתונים

- **endpoints**: מערך אובייקטים, אחד לכל endpoint
- **כל endpoint מכיל**:
  - `path`: נתיב ה-API
  - `method`: שיטת HTTP
  - `p50_ms`, `p95_ms`, `p99_ms`: אחוזוני זמן תגובה במילישניות
  - `error_rate`: שיעור שגיאות (0-1)
  - `rps`: בקשות לשנייה (ממוצע דקה אחרונה)
  - `status`: מצב בריאות — `healthy` / `degraded` / `critical`
  - `thresholds`: ספי התראה מוגדרים
- **summary**: סיכום כלל-מערכתי

## שימוש

הזן את `payload` ישירות לרכיב התצוגה. הרכיב ימיין אוטומטית לפי חומרה (critical ראשונים) וידגיש חריגות סף.
