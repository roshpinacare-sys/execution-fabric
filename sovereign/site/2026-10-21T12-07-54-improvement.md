# מדריך שימוש: לוח-המשימות — ניווט, סינון וניהול יומי

> **קהל יעד**: מפעילים/ות המשתמשים בלוח-המשימות בקונסולת RTL בעברית על בסיס יומי.
> **זמן קריאה משוער**: 5–7 דקות.

---

## 1. מבט-על מהיר

לוח-המשימות מציג את כל המשימות במערכת, מאורגנות בעמודות לפי סטטוס (תור). כל עמודה = תור. כל כרטיס = משימה.

| עמודת ברירת-מחדל | משמעות | פעולה נפוצה |
|-------------------|---------|-------------|
| `BACKLOG`         | ממתינות לתכנון | גרירה ל-`READY` כשמוכנות |
| `READY`           | מוכנות לביצוע   | הקצאה לעובד (`Assign`) |
| `IN_PROGRESS`     | בביצוע כרגע     | עדכון התקדמות / סיום |
| `REVIEW`          | ממתינות לבדיקה | אישור / החזרה |
| `DONE`            | הושלמו          | ארכוב / צפייה בהיסטוריה |
| `FAILED`          | נכשלו           | ניתוח שגיאה / הפעלה מחדש |

> **טיפ**: סדר העמודות ניתן להתאמה אישית דרך תפריט «הגדרות תצוגה» (ראה סעיף 4).

## 2. ניווט מקלדת מלא (ללא עכבר)

| מקש / צירוף | פעולה |
|--------------|--------|
| `Tab` / `Shift+Tab` | מעבר בין אזורים: סרגל עליון → עמודות → כרטיסים → פרטי משימה |
| `←` / `→` | מעבר בין עמודות (תורים) |
| `↑` / `↓` | מעבר בין כרטיסים בתוך עמודה |
| `Enter` | פתיחת פרטי משימה (מודל צד) |
| `Esc` | סגירת מודל / ביטול עריכה |
| `/` | פוקוס לשדה חיפוש/סינון מהיר |
| `Ctrl+K` | פתיחת פלטת פקודות (Command Palette) |
| `A` (כשכרטיס בפוקוס) | הקצאה מהירה לעצמי (`Assign to me`) |
| `M` (כשכרטיס בפוקוס) | העברה לעמודה הבאה (`Move forward`) |
| `Shift+M` | העברה לעמודה הקודמת (`Move back`) |
| `D` | סימון כ-`DONE` (מכל מקום בכרטיס) |
| `F` | סימון כ-`FAILED` + פתיחת שדה סיבת כישלון |

> **נגישות**: כל הפעולות לעיל נתמכות בקוראי מסך. מצב ניגודיות גבוה מופעל אוטומטית כשהמערכת מזהה העדפת `prefers-contrast: more` בדפדפן.

## 3. סינון וחיפוש — למצוא בדיוק את מה שצריך

### 3.1 סינון מהיר (שורת החיפוש העליונה)
- **טקסט חופשי**: חיפוש בכותרת, תיאור, מזהה, תגיות.
- **אופרטורים**:
  - `assignee:שם` — משימות המוקצות למשתמש מסוים
  - `tag:באג` / `tag:פיצ'ר` — סינון לפי תגית
  - `status:IN_PROGRESS` — סטטוס ספציפי (עוקף תצוגת עמודות)
  - `priority:high` / `priority:critical` — עדיפות
  - `age:>3d` — משימות פתוחות יותר מ-3 ימים
  - `blocked:true` — משימות חסומות

### 3.2 תצוגות שמורות (Saved Views)
לחיצה על אייקון 💾 בשורת הסינון → «שמור תצוגה נוכחית».
תצוגות מומלצות להגדרה חד-פעמית:

| שם תצוגה | שאילתה | מתי להשתמש |
|-----------|---------|--------------|
| «שלי היום» | `assignee:me status:IN_PROGRESS,READY` | תחילת יום / תכנון יומי |
| «ממתינות לי» | `status:REVIEW assignee:me` | לפני סגירת יום |
| «תקועות» | `blocked:true age:>2d` | שבועי / ניקוי צווארי-בקבוק |
| «קריטיות פתוחות» | `priority:critical status:BACKLOG,READY,IN_PROGRESS` | תגובה מהירה |

## 4. התאמה אישית של התצוגה

פתיחה: לחיצה על גלגל שיניים ⚙️ בפינה הימנית-עליונה של הלוח.

### אפשרויות עיקריות:
- **סדר עמודות**: גרירה ושחרור של כותרות עמודות לשינוי סדר.
- **הסתרת עמודות**: ביטול סימון ✓ ליד שם עמודה → העמודה מוסתרת (הנתונים נשמרים).
- **צפיפות כרטיסים**: `Compact` / `Comfortable` / `Spacious` — שליטה בגובה כרטיס וכמות שדות גלויים.
- **שדות גלויים בכרטיס**: בחירה אילו שדות יופיעו ישירות על הכרטיס (עדיפות, תגיות, מקצה, זמן מוערך, תאריך יעד).
- **צבעוניות לפי**: עדיפות / סוג משימה / מחלקה / מצב חסימה.
- **הצגת מונה לכל עמודה**: מופעל כברירת-מחדל.

## 5. זרימות עבודה יומיות מומלצות

### 5.1 פתיחת יום (5 דקות)
1. פתח תצוגה «שלי היום» (`Ctrl+K` → הקלד «שלי היום» → Enter).
2. עבור על `READY` — הקצה לעצמך (`A`) משימות שאתה לוקח היום.
3. בדוק `IN_PROGRESS` — האם כולן מתקדמות? עדכן הערות התקדמות בלחיצת `Enter` → לשונית «הערות».
4. סרוק «תקועות» — אם יש משימות חסומות מעל 48 שעות, הסר חסימה או הסלם.

### 5.2 במהלך היום
- **סיום משימה**: פוקוס על כרטיס → `D` → אשר. הכרטיס עובר ל-`DONE`.
- **צורך בבדיקה**: `M` (העברה קדימה) → הכרטיס עובר ל-`REVIEW`.
- **נתקעת?**: `F` → הזן סיבת כישלון קצרה → הכרטיס עובר ל-`FAILED` עם הקשר.
- **הערה מהירה**: `Enter` → כתוב הערה → `Ctrl+Enter` לשמירה מהירה.

### 5.3 סגירת יום (3 דקות)
1. פתח «ממתינות לי» — אשר או החזר משימות ב-`REVIEW`.
2. ודא שאין משימות `IN_PROGRESS` ללא עדכון התקדמות היום.
3. אם יש משימות `READY` שהקצת לעצמך ולא התחלת — שקול להחזיר ל-`BACKLOG` או להקצות לאחר.
4. רענן תצוגה «תקועות» — טפל בחדשות.

## 6. פעולות מתקדמות (פלטת פקודות `Ctrl+K`)

| פקודה | תיאור |
|--------|-------|
| `משימה: צור חדשה` | פתיחת טופס יצירה מהירה עם שדות חובה בלבד |
| `משימה: שכפל` | שכפול כרטיס נוכחי (שימושי למשימות חוזרות) |
| `משימה: ייצא ל-CSV` | ייצוא התצוגה המסוננת הנוכחית |
| `תור: צור מותאם` | הוספת עמודה/תור מותאם אישית |
| `תצוגה: אפס לברירת-מחדל` | החזרת כל הגדרות התצוגה לברירת-מחדל |
| `סינון: נקה הכל` | איפוס מהיר של כל המסננים |

## 7. קיצורי-דרך שווים זהב

- **גרירה עם `Alt` לחוץ** → העתקת משימה לעמודה אחרת (במקום העברה).
- **לחיצה ימנית על כרטיס** → תפריט הקשר מלא (כל הפעולות + קישור ישיר ללוג שרשרת).
- **`Shift+Click` על מספר כרטיסים** → בחירה מרובה → פעולות בכמות (הקצאה, העברה, תגיות, ייצוא).
- **הקלדת `#` בשדה חיפוש** → השלמה אוטומטית של מזהי משימות אחרונות.

## 8. פתרון בעיות נפוצות

| תסמין | סיבה אפשרית | פתרון |
|--------|--------------|--------|
| כרטיס לא נגרר | מצב `READ_ONLY` / הרשאות חסרות | בדוק הרשאות תפקיד / פנה למנהל |
| סינון לא מחזיר תוצאות | תו רווח סמוי / אופרטור שגוי | נקה סינון (`Ctrl+K` → «סינון: נקה הכל») והתחל מחדש |
| עמודות חסרות | הוסתרו בהגדרות תצוגה | ⚙️ → החזר סימון לעמודות הרצויות |
| קיצורי מקלדת לא עובדים | פוקוס בשדה קלט (חיפוש, הערה) | `Esc` ליציאה מהשדה → נסה שוב |

## 9. קישורים שימושיים

- **מדריך קונסולת RTL** — ניווט כללי, פקודות גלובליות, הגדרות משתמש.
- **מדריך ניהול תורים והקצאות** — עומק על הגדרת תורים, חוקי ניתוב, אוטומציות.
- **צ'ק-ליסט יומי לריבון** — רשימת ביקורת בריאות מערכת מקיפה.
- **דשבורד בריאות מערכת** — מדדים בזמן אמת על תורים, שרשרת, העברות.
