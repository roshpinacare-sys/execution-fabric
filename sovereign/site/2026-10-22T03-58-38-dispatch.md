# התאמת לוח המשימות (Dispatch) למובייל: כרטיסי משימה רספונסיביים עם פעולות נגיעה

# הצעה: התאמת לוח המשימות (Dispatch) למובייל

## הבעיה
לוח המשימות הנוכחי (`DispatchBoard`) בנוי כטבלה (`<table>`) עם עמודות קבועות. במובייל (< 640px):
- גלילה אופקית שבורה — כותרות נעלמות, תוכן נחתך
- כפתורי פעולה (התחל/השהה/השלם) קטנים מדי לאצבע (פחות מ-44×44px)
- אין משוב ויזואלי ללחיצה (ripple/active state)
- צפיפות מידע גבוהה גורמת לטעויות הקשה

## הפתרון המוצע
### 1. פריסה רספונסיבית: טבלה ← כרטיסים

### 2. מבנה כרטיס משימה (Mobile)
```tsx
// TaskCardMobile.tsx
interface TaskCardProps {
  task: Task;
  onAction: (taskId: string, action: TaskAction) => void;
}

export function TaskCardMobile({ task, onAction }: TaskCardProps) {
  const [expanded, setExpanded] = useState(false);
  
  return (
    <article className={`task-card ${expanded ? 'expanded' : ''}`}>
      {/* Header: ID + Status badge */}
      <div className="card-header" onClick={() => setExpanded(!expanded)}>
        <span className="task-id">#{task.id.slice(-6)}</span>
        <StatusBadge status={task.status} size="sm" />
        <ChevronIcon rotated={expanded} />
      </div>

      {/* Core info: always visible */}
      <div className="card-core">
        <h3 className="task-title">{task.title}</h3>
        <div className="task-meta">
          <span className="worker">{task.assignedWorker || 'ללא הקצאה'}</span>
          <span className="duration">{formatDuration(task.elapsed)}</span>
        </div>
      </div>

      {/* Expanded: details + actions */}
      {expanded && (
        <div className="card-expanded">
          <div className="task-description">{task.description}</div>
          <div className="task-tags">
            {task.tags.map(t => <Tag key={t} size="sm">{t}</Tag>)}
          </div>
          <div className="card-actions" role="group" aria-label="פעולות משימה">
            {getAvailableActions(task).map(action => (
              <button
                key={action}
                className={`btn btn-${action.variant} touch-target`}
                onClick={() => onAction(task.id, action.type)}
                disabled={action.disabled}
              >
                {action.icon} {action.label}
              </button>
            ))}
          </div>
        </div>
      )}
    </article>
  );
}
```

### 4. סרגל ניווט תחתון קבוע (Bottom Nav)
```tsx
// DispatchBottomNav.tsx - מוצג רק במובייל
export function DispatchBottomNav() {
  const [activeTab, setActiveTab] = useState<'all' | 'active' | 'mine'>('all');
  
  return (
    <nav className="bottom-nav" role="navigation" aria-label="סינון משימות">
      <button
        className={activeTab === 'all' ? 'active' : ''}
        onClick={() => setActiveTab('all')}
        aria-pressed={activeTab === 'all'}
      >
        <ListIcon /> <span>הכל</span>
      </button>
      <button
        className={activeTab === 'active' ? 'active' : ''}
        onClick={() => setActiveTab('active')}
        aria-pressed={activeTab === 'active'}
      >
        <ActivityIcon /> <span>פעילות</span>
      </button>
      <button
        className={activeTab === 'mine' ? 'active' : ''}
        onClick={() => setActiveTab('mine')}
        aria-pressed={activeTab === 'mine'}
      >
        <UserIcon /> <span>שלי</span>
      </button>
    </nav>
  );
}
```

### 5. נגישות (a11y)
- **ARIA**: כל כרטיס — `article` עם `aria-labelledby` לכותרת
- **מקלדת**: `Tab` בין כרטיסים, `Enter/Space` להרחבה, `Esc` לסגירה
- **Screen Reader**: סטטוס מוכרז בשינוי (`aria-live="polite"`)
- **ניגודיות**: יחס 4.5:1 מינימום לכל טקסט וכפתורים
- **זום**: תומך ב-200% זום בלי גלילה אופקית
