# דשבורד בריאות רשת — מדריך שימוש

## מטרה
מספק תמונת-מצב מיידית של בריאות הרשת האוטונומית — מיועד למסך משמרת-לילה, התראות אוטומטיות, וקבלת החלטות מהירה.

## שדות ה-payload
כל השדות מחושבים בזמן אמת ממטא-דאטת הרשת. ערכי-סף (thresholds) מסומנים לצד כל מדד.

### 1. שרשרת-אמת (Ledger)
- `chain.done` — בלוקים שהושלמו בהצלחה
- `chain.failed` — בלוקים שנכשלו  
- `chain.successRate` — אחוז הצלחה (יעד: ≥ 95%)
- `chain.health` — `healthy` | `degraded` | `critical`

### 2. תור משימות (Task Queue)
- `tasks.done` — משימות שהושלמו
- `tasks.failed` — משימות שנכשלו
- `tasks.pending` — משימות ממתינות (נגזר מ-openLoops)
- `tasks.throughputPerHour` — קצב עיבוד לשעה
- `tasks.health` — סטטוס בריאות התור

### 3. זיכרון ולמידה (Memory & Learning)
- `memory.learned` — סך ממצאים שנלמדו
- `memory.produced` — תובנות שיוצרו
- `memory.delivered` — תובנות שנמסרו למוצר
- `memory.openLoops` — לולאות פתוחות הדורשות טיפול (יעד: 0)
- `memory.learningVelocity` — קצב למידה ל-24ש (ממצאים/יום)

### 4. שיפורים (Improvements)
- `improvements.total` — סך כל השיפורים
- `improvements.byKind.CONTENT/DATA/PROPOSAL` — פילוח לפי סוג
- `improvements.recentVelocity` — שיפורים ב-7 ימים אחרונים

### 5. התראות פעילות (Active Alerts)
מערך אובייקטים — כל התראה מכילה:
- `severity`: `critical` | `attention` | `watch`
- `kind`: `execution` | `memory` | `chain` | `tasks`
- `title`: כותרת קצרה
- `detail`: פירוט טכני
- `since`: timestamp התחלה
- `acknowledged`: boolean

### 6. משמרת-לילה (Night Watch)
- `nightWatch.arteryPacer.status`: `running` | `stalled` | `restarting`
- `nightWatch.arteryPacer.lastHeartbeat`: ISO timestamp
- `nightWatch.arteryPacer.timeouts24h`: ספירת timeouts ביממה
- `nightWatch.arteryPacer.health`: סטטוס כולל

## תצוגה בקונסולת RTL
```javascript
// דוגמת רינדור בסיסי
const render = (data) => {
  const healthColor = {
    healthy: '\x1b[32m',    // ירוק
    degraded: '\x1b[33m',   // צהוב
    critical: '\x1b[31m'    // אדום
  };
  
  console.log('╔══════════════════════════════════════╗');
  console.log('║  דשבורד בריאות רשת — משמרת לילה    ║');
  console.log('╠══════════════════════════════════════╣');
  console.log(`║ שרשרת: ${healthColor[data.chain.health]}${data.chain.successRate.toFixed(1)}%\x1b[0m  | תור: ${healthColor[data.tasks.health]}${data.tasks.throughputPerHour}/ש\x1b[0m  | לולאות: ${data.memory.openLoops} ║`);
  console.log(`║ עורק-לב: ${healthColor[data.nightWatch.arteryPacer.health]}${data.nightWatch.arteryPacer.status}\x1b[0m  | Timeouts: ${data.nightWatch.arteryPacer.timeouts24h} ║`);
  console.log('╚══════════════════════════════════════╝');
  
  if (data.alerts.length) {
    console.log('\n🚨 התראות פעילות:');
    data.alerts.forEach(a => console.log(`  [${a.severity}] ${a.title}`));
  }
};
```
