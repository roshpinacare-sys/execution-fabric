# כרטיס 'צי-הכלים' אינטראקטיבי: הרצה, מעקב סטטוס והיסטוריה ישירות מהקונסולה

## הקשר נוכחי
כרטיס **צי-הכלים** בקונסולת RTL מציג כיום רשימת פעולות (actions) עם תיאור, פרמטרים וקטגוריה — אך **אין דרך להריץ אותן, לראות סטטוס ריצה נוכחי או היסטוריה** בלי לעזוב את הקונסולה ל-API נפרד.

## ההצעה — שלושה שדרוגי-UX ממוקדים

### 1. כפתור "הרץ" (Run) בכל שורת פעולה
- **מיקום**: עמודת "פעולות" חדשה בטבלה (או תפריט ⋮ בסוף השורה).
- **התנהגות**:
  - לחיצה פותחת מודל קטן עם שדות הפרמטרים (לפי סכימת JSON Schema של הפעולה).
  - שדות חובה מסומנים; ברירות-מחדל נטענות מה-schema.
  - כפתור "אישור" שולח `POST /api/arsenal/actions/{id}/run` עם גוף הבקשה.
  - תגובה מיידית: `runId` + סטטוס התחלתי `QUEUED`.

### 2. פס התקדמות וסטטוס חי (Live Status)
- לאחר הרצה, השורה מתרחבת **inline** (אקורדיון) ומציגה:
  - **סטטוס**: `QUEUED → RUNNING → DONE/FAILED` עם צבעוניות סמנטית.
  - **זמן התחלה / סיום משוער / משך ריצה**.
  - **לוגים אחרונים** (3-5 שורות, מתעדכנים ב-SSE/WS מ-`/api/arsenal/runs/{runId}/stream`).
  - כפתור "פתח בלוק Ledger" — קישור ישיר ל-`/ledger/{blockHash}` כשהסטטוס `DONE`.
- עדכון אוטומטי כל 2 שניות עד סיום; כפתור "רענן" ידני לגיבוי.

### 3. לשונית "היסטוריית הרצות" (Run History)
- בראש הכרטיס: טאב נוסף "היסטוריה" לצד "פעולות".
- טבלה עם עמודות: `Run ID`, `פעולה`, `סטטוס`, `התחלה`, `סיום`, `משך`, `בלוק Ledger`.
- סינון: לפי פעולה, טווח תאריכים, סטטוס.
- מיון: לפי זמן התחלה (ברירת מחדל יורד).
- לחיצה על שורה → אותו פאנל inline עם לוגים מלאים וקישור Ledger.
- נתונים נטענים מ-`GET /api/arsenal/runs?actionId=&status=&from=&to=&limit=50` עם פגינציה.

## נקודות API נדרשות (למימוש עתידי)
| נקודה | שיטה | תיאור |
|----------|-------|---------|
| `/api/arsenal/actions/{id}/run` | POST | התחלת הרצה, מחזיר `{ runId, status: "QUEUED" }` |
| `/api/arsenal/runs/{runId}` | GET | פרטי ריצה מלאה כולל לוגים |
| `/api/arsenal/runs/{runId}/stream` | GET (SSE) | זרם עדכוני סטטוס/לוגים בזמן-אמת |
| `/api/arsenal/runs` | GET | היסטוריה עם שאילתות סינון/מיון/עמוד |

## עיצוב RTL ומובייל
- מודל פרמטרים: רוחב 90% במובייל, 520px בדסקטופ, כיוון RTL מלא.
- פאנל inline: גובה מקסימלי 300px עם גלילה פנימית; במובייל — מסך מלא (bottom sheet).
- צבעי סטטוס: תכלת (QUEUED), כתום (RUNING), ירוק (DONE), אדום (FAILED) — נגישים למצב ניגודיות גבוה.
- מקלדת: `Enter` בשדה אחרון = הרצה; `Esc` סוגר מודל/פאנל.

## ערך מיידי
- **זמן למשימה**: מ-"פתח API docs → העתק curl → הרץ → חפש בלוגים" ל-2 קליקים בקונסולה.
- **נראות**: כל הרצה משאירה עקבות ב-Ledger — שקיפות מלאה בלי מאמץ.
- **אימוץ**: צי-הכלים הופך מ"רשימת יכולות" ל"מרכז בקרה" — מגדיל שימוש בפעולות אוטומציה.

## סיכונים והפחתה
| סיכון | הפחתה |
|-------|--------|
| הרצה מקרית של פעולה הרסנית | פעולות עם `destructive: true` דורשות הקלדת שם הפעולה לאישור במודל |
| עומס SSE על שרת | חיבור יחיד לכרטיס; ניתוק אוטומטי כשהטאב לא פעיל |
| היסטוריה גדולה | ברירת מחדל 50 רשומות; אינדקס DB על `(actionId, startedAt)` |

## קריטריוני קבלה (Definition of Done)
1. כפתור "הרץ" מופיע לכל פעולה עם `runnable: true` בסכימה.
2. מודל פרמטרים נטען דינמית מה-schema; ולידציה צד-לקוח לפני שליחה.
3. פאנל inline מציג סטטוס חי מתעדכן ב-SSE עד סיום.
4. לשונית היסטוריה טוענת 50 רשומות אחרונות עם סינון/מיון עובדים.
5. קישור Ledger נפתח בטאב חדש עם hash נכון כשסטטוס `DONE`.
6. כל רכיבי RTL, מובייל, מקלדת וניגודיות עוברים בדיקת נגישות ידנית.
