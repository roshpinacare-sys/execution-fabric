## שכבה-4 בפירוט — הזקיפה (Task 71)

**משימות:**
1. **זקיפה**: fabric-heartbeat (:3031) ו-chain-witness (:3050) נבדקים-כל-10ש. 3 כשלים-רצופים
   (~30ש) = הזנקה מחדש (`bun run dev`, בן-מנותק), backoff-120ש בין-הזנקות-של-אותו-שירות
   (מנע-סערת-הזנקות). האפליקציה (:3000) — **נצפית-בלבד**: הזנקתה היא סמכות-הלב (עורק-0);
   אחריות-אחת-לכל-מי, אפס-כפילות-סמכות. אם-הלב-מת-והאפליקציה-עמו — הזקיפה מחייה-את-הלב,
   והלב-המחודש מחייה-את-האפליקציה: שרשרת-סמכות-ברורה.
2. **מראת-גיבוי-מקומית**: bare-mirror-clone מלא של הריפו, מחוץ-לעץ-הפרויקט
   (`../fabric-mirror.git` — נגזרת-מיקום-עצמי, אפס-נתיבי-מכונה-בעץ). מתעדכנת-כל-30דק'
   דרך-credential-helper הקיים (הטוקן-אף-פעם-לא-נוגע-בדיסק; אין-טוקן-ב-config של-המראה).
   השדה `synced` הוא-כנות-חיה: השוואת-ראש-המראה מול-ראש-origin/main-המקומי — אם-הדחיפות-האחרונות-עוד-לא-הגיעו-למראה, synced:false.
3. **תמונות-db**: כל-שעה `VACUUM INTO` מחיבור-readonly אל-`../fabric-backups/`
   (עותק-עקבי-אטומי של-השרשרת-בזמן-כתיבה; fallback-כן: העתקת-db+wal+shm).
   מלאי-מוגבל-ל-24-תמונות-אחרונות. ניתנות-להצלבה מול-העד בכל-רגע.

**מה-הזקיפה-לא-עושה (מכוון):** אין-כתיבה-לשרשרת (פעולת-הזקיפה-היא-רפלקס, לא-רישום-עובדות;
המצב-חי-דרך-/health-ו-census), אין-גיט-כתיבה, אין-נגיעה-בסודות, אין-הזנקת-אפליקציה.

## העד-הדו-מימושי (Task 73 — מחזור-חדשנות #6)

מאז-Task-73 העד-מפעיל **שני-מימושים-בלתי-תלויים** של-האימות-הקנוני, בכל-פעימה:
- **טעינה-מלאה** (מימוש-ההיסטורי): SELECT-אחד-שטוח → אימות-מלא. O(n)-זיכרון.
- **זרימה** (מימוש-#6): keyset pagination (`WHERE id > ? LIMIT 500`) → אותו-אימות-מלא
  מה-Genesis, **בלי-דלתא ובלי-checkpoint** — דגם-האמונים-של-המפקח-נשמר-שלם; הזיכרון
  חסום-ב-O(מנת-אצווה) — קריטי-בשירות-חי-לנצח-עם-שרשרת-צומחת.
- **הצלבה-מלאה**: כל-עדות = שני-המימושים-מסכימים ביט-ביט (ok/total/verified/head/brokenAt).
  סתירה = `self-divergence` → ok:false גלוי. עד-שבודק-את-עצמו.
- **מדידה-חתומה**: כל-עדות נושאת streamMs/loadInMs; `GET :3050/bench?runs=N` מדידה-רשמית;
  חתימת-INNOVATION דרך `POST /api/sovereign/innovation?subject=witness` — האמת-על-ביצועי-
  העד מקורה-בעד-עצמו. מדידה-מוכחת-על-752-רשומות: זרימה ×1.092-מהטעינה (מספר-כן;
  האימוץ-מנומק-בחסימות-הזיכרון, לא-במהירות).

## גבולות-כנים (החלק-החשוב)

- **מראה-מקומית ≠ גיבוי-חוץ**: המראה-והתמונות-חיות-על-אותו-סנדבוקס. הן-מגינות משחיתות-עץ,
  קומיטים-מקומיים-אבודים, ו-db-פגום — **לא ממחיקת-סנדבוקס**. מול-מחיקה-גורפת: העוגן-הוא
  github + עורק-ח (הוכח-ריצה: clone-טרי = השרשרת-כולה-מאומתת, קידומת-מאומתת של החיה).
- **מראות-חוץ-אמיתיות** (Codeberg/GitLab/self-host): מותרות-רק-בקרדנציאלים-שהבעלים-יוצר-בעצמו
  — חוק-אדום, ראו docs/BEYOND-GITHUB.md (איסור-מוחלט על-יצירת-חשבונות-על-ידי-סוכנים).
- **מי-משגיח-על-הזקיפה?** הזקיפה-אינה-אלוהות. שכבת-הגנה-שלה: bun --hot (העץ-המתמיד),
  כלב-השמיר-של-הלב, ה-badge-חי-בדף-לבעלים, והעובדה-שהשרשרת-עצמה-ממשיכה-לצמוח — שקטת-הזקיפה-ניכרת-מיד ב-census.
- **EADDRINUSE**: אם-מופע-זומבי-מחזיק-פורט — ההזנקה-החדשה-נופלת-בכנות-והסבב-הבא-ינסה-שוב.
  מוות-גלוי-עדיף-על-שקר-שקט.
